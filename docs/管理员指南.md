# 管理员指南（设置页逐项说明）

侧边栏进入「设置」。页面标题下有一行说明：超管看到的是"管理外观、服务器、成员与权限"，
其他角色看到的是"个性化浏览体验"。

九个标签页：

| 标签页 | 谁能看到 | 一句话说明 |
|:---------------- |:------------- |:--------------------------------------- |
| **外观** | 所有人 | 主题、默认视图与排序偏好（只存在你自己的浏览器里） |
| **状态** | 仅超管 | 运行时长、占用、访问地址，每 10 秒自动刷新 |
| **日志与指标** | 仅超管 | 系统与请求指标、慢请求列表，以及最近 N 天的操作日志（可筛选、可清空） |
| **成员** | 仅超管 | 批量创建团队成员、启用 / 禁用 / 改名 / 重置密码 / 删除 |
| **小组** | 仅超管 | 新建 / 编辑小组：成员与组长、可见范围、权限收窄、组长能力 |
| **权限** | 仅超管 | 上传与打包上限、成员 19 项 / 访客 8 项权限开关、访客隐藏列表 |
| **数据与保留** | 仅超管 | 头像与团队待办开关、默认上下文可见范围、日志 / 指标保留天数、数据备份与回滚 |
| **安全** | 仅超管 | 限流、解压总量上限、四个安全开关、客户端 IP 解析说明 |
| **公网** | 仅超管 | SSH 反向隧道的开启 / 模式选择 / 运行状态与日志 |

> 点开标签页里任何**开关**都是**即时保存**的；带**输入框 + 保存按钮**的项目必须点「保存」才生效。

## 状态

每 10 秒自动拉取一次（数据来自 `GET /api/admin/status`）。

### 六个指标卡

| 卡片 | 含义 |
|:-------- |:--------------------------------------- |
| **运行** | 服务已运行时长，格式如 `3 天 4 小时` / `2 小时 15 分钟` / `8 分钟 12 秒` |
| **存储** | 网盘文件根目录下的文件总占用 |
| **内存** | 当前进程的常驻内存（RSS） |
| **Node** | 服务运行的 Node.js 版本 |
| **文件数** | `N 文件 / M 文件夹`（递归统计） |
| **磁盘** | 文件根目录所在磁盘的可用空间；获取不到时显示「不可用」，不影响其他功能 |

> 存储与文件数的统计**最多扫描 20 万个条目**，结果带有 30 秒缓存；条目极多时会标记为部分统计。

### 局域网访问

列出可用的访问地址，每行有标签与可复制的只读输入框：

- `本机`：`http://localhost:<端口>`
- `局域网`：本机每个非回环 IPv4 地址各一行
- `公网`：**仅当隧道正在运行且已抓到公网地址时出现**

## 日志与指标

这一页分三块：**系统指标**、**请求指标**、**操作日志**。指标每 10 秒自动刷新一次。

### 系统指标

数据来自 `GET /api/admin/metrics`：服务端**每分钟**采样一次，内存里保留最近
`metricsMemMinutes`（默认 15）分钟，同时按天写入 `data/metrics/zs-YYYY-MM-DD.jsonl`
（保留 `metricsRetentionDays` 天，默认 7）。

| 卡片 | 含义 |
|:-------- |:--------------------------------------- |
| **CPU** | 进程 CPU 使用率（%），带一条最近 N 分钟的迷你曲线 |
| **内存** | 系统内存使用率（%），副标题是 `进程 RSS / 系统总内存` |
| **磁盘** | 文件根目录所在磁盘的可用 / 总空间；取不到时显示 `—` |
| **文件** | `N 文件 / M 文件夹 · 总占用` |

### 请求指标

- 顶部五个数字：**QPS**（最近窗口内的平均每秒请求数）、**2xx**、**4xx**、**5xx**、**慢请求**（最近一分钟）；
- 下方表格列出最近的**慢请求**（方法 / 路径 / 状态码 / 耗时），耗时达到 `slowRequestMs`
  （默认 1000 毫秒）的请求才会进入这个列表；
- 可以在「设置 → 数据与保留 → 日志与指标保留」里关闭采集（`requestMetricsEnabled`）
  或调整慢请求阈值。关闭后这几个卡片会一直是 `—`，但**不影响服务本身**。

### 操作日志

- **数据来源**：`data/logs/zs-YYYY-MM-DD.log`，按天一个文件，每行一个 JSON 对象。
- **展示范围**：默认读取**最近 5 个**日志文件，界面一次最多取 300 条，**最新在最上面**；
  天数下拉可切到 `1 天` / `5 天` / `30 天`（接口最多接受 90 天）。
- **筛选**：级别（全部 / 信息 / 警告 / 错误）、天数、**仅审计事件**开关、关键词
  （在事件名、详情、用户名、IP、角色里匹配），回车或点「刷新」重新查询。
  「仅审计事件」只保留登录、权限与配置变更、成员 / 小组 / 待办 / 头像变更、文件写操作、
  备份与回滚、日志清空、隧道开关这类关键事件（完整名单见 `server/src/logger.js` 的 `AUDIT_EVENTS`）。
- **概览徽章**：表格上方显示「共 N 条」、信息 / 警告 / 错误各自的条数，以及出现次数最多的几个事件名。
- **清空**：点「清空」→ 确认框 → 删除日志目录下所有 `.log` 文件（此动作会记一条 `logs_clear` 日志）。
- 表格列：时间 / 事件 / 用户 / IP / 详情。鼠标悬停可以看到被截断的完整内容。

> 日志文件本身按 `logRetentionDays`（默认 30 天）自动清理，删除的是**超过保留期的整天文件**。

### 常见事件名

| 事件 | 含义 |
|:--------------------------- |:--------------------------------------- |
| `server_start` | 服务启动 |
| `trust_proxy` | 启动时打印生效的 `TRUST_PROXY` 模式 |
| `download_url_relaxed` | 启动时提示链接下载的 SSRF 限制被放开 |
| `login_success` / `login_fail` | 登录成功 / 失败（含用户名与 IP） |
| `login_locked` | 某账户因连续失败被临时锁定 |
| `logout` / `password_change` | 退出登录 / 成员修改密码 |
| `mkdir` `upload` `rename` `delete` `copy` `move` `save_file` | 文件写操作 |
| `download` | 单文件下载（内联预览不记录，避免刷屏） |
| `download_zip` | 打包下载 |
| `compress` / `extract` | 在线压缩 / 解压完成 |
| `guest_visibility` | 修改了某个文件夹的访客可见性 |
| `config_update` | 后台设置被修改（详情里是本次改动的 JSON） |
| `members_create` / `members_batch` / `members_reset_password` / `members_rename` | 成员管理动作 |
| `group_create` / `group_update` / `group_delete` | 小组的新建 / 修改（含成员与可见范围调整） / 删除 |
| `todo_create` / `todo_update` / `todo_done` / `todo_delete` | 团队待办的新建 / 修改 / 勾选完成 / 删除 |
| `avatar_update` / `avatar_delete` | 头像更新 / 删除（详情里是头像所属的账户标识） |
| `backup_create` / `backup_restore` | 手动创建数据快照 / 回滚某个数据文件 |
| `metrics_start` / `metrics_sample_fail` | 指标采集启动 / 某次采样失败 |
| `logs_clear` | 清空日志 |
| `tunnel_start` / `tunnel_stop` / `tunnel_url` / `tunnel_exit` / `tunnel_error` / `tunnel_enable` / `tunnel_disable` | 隧道相关 |
| `server_error` | 服务端 5xx 错误（含请求方法、路径、错误信息、IP） |
| `unhandled_rejection` / `uncaught_exception` | 进程级兜底捕获到的异常（**只记日志、不退出进程**，见 [开发者指南](开发者指南.md#31-请求处理链serverindexjs-的中间件顺序)） |

> 想让服务**只写日志文件、不在控制台输出**（例如作为服务在后台跑）：
> 在 `.env` 里设 `NOLOG=true`，或者启动时加参数 `-nolog`
> （用 pnpm 传参要写成 `pnpm start -- -nolog`）。

## 成员

「团队成员（低级管理员）」这一栏管理所有成员账号。**超管自己不在这里**，也删不掉。

### 添加成员

点「添加成员」打开「批量添加成员」：

- **每行一个账户**，格式为 `用户名 密码`（空格、半角逗号、全角逗号都能分隔）；
- **省略密码会自动生成一个随机密码**；
- 允许的写法示例：

```
alice 123456
bob
carol pass888
```

- 规则提示：用户名 2–32 位（字母 / 数字 / `_` `.` `-`），密码至少 6 位；
- 一次最多提交 **200** 个，成员总数上限 **500**；
- 创建完成后会在页面上显示「创建成功，请保存账号信息（用户名 密码）」，**这段信息只显示这一次**，请复制保存；
- 失败的条目会逐条弹出错误提示（例如"用户名已存在"、"该用户名已被超级管理员占用"、"本次提交中用户名重复"）。

### 成员表格

勾选框 / 用户名 / 状态（`正常` 或 `已禁用`）/ 创建时间 / 操作（`⋮`）。

**选中若干人之后**，工具栏会出现：`启用`、`禁用`、`批量重置密码`、`删除`。

**单个成员**点 `⋮` 或右键，可以：

| 操作 | 说明 |
|:------------ |:--------------------------------------- |
| 启用 / 禁用 | 禁用会立刻让其所有登录会话失效（登录会提示"该账户已被禁用"） |
| 更改用户名 | 新名字仍要满足 2–32 位规则，且不能与超管或其他成员重名 |
| 重置密码 | 可手填或点「随机生成」；重置后该成员的所有旧会话立刻失效 |
| 删除 | 二次确认，**不可撤销** |

## 小组

「小组」是给**团队成员**用的"上下文"：成员可以同时属于多个小组，在顶栏切换小组后，
**文件的可见范围、有效权限与团队待办**都会随之变化。小组**不会**改变"超级管理员 / 成员 / 访客"
三种角色，只会在超管设定的全局范围内**收窄**。

页面顶部是小组卡片网格，右上角是「新建小组」。每张卡片显示：

- 组名前的**颜色圆点** + 组名 + 右侧 `⋯` 菜单（**编辑小组** / **删除**）；
- 统计行：`N 成员`、`N 组长`、可见范围（`可见不限` 或 `白名单 N`，有黑名单时追加 `· 隐藏 N`）；
- 成员名一行（超出会被截断）。

没有小组时显示「还没有小组 · 点击右上角「新建小组」，为不同团队划分可见范围与权限」。

### 新建 / 编辑小组

对话框有四个标签页：**基本** / **成员** / **可见范围** / **权限**（成员数与可见范围项数会以角标提示）。
顶部说明写着同一件事：**小组只做「收窄」**，可见范围与权限都只能在全局范围内收紧，不会放宽。

#### 基本

| 项目 | 说明 |
|:-------------- |:--------------------------------------- |
| 小组名称 | 必填，最多 **40** 个字符，支持中英文、数字、空格与 `_` `.` `-`；重名（不区分大小写）会被拒绝 |
| 小组颜色 | 取色器，显示在卡片与顶栏切换器里 |
| 组长权限 | 超管下放给组长的能力开关，共四个，见下表 |

**组长能力**（`leaderCaps`）：

| 开关 | 配置字段 | 默认 | 开启后组长可以做 |
|:-------------------------------- |:------------------ |:-------- |:--------------------------------------- |
| 查看本组成员名单 | `viewMembers` | **开** | 在「团队」页看到本组成员名单 |
| 创建 / 编辑本组待办 | `manageTodo` | **开** | 向本组或本组成员下发待办、编辑与删除自己管辖范围内的待办 |
| 修改本组成员头像 | `editMemberAvatar` | **关** | 通过接口为本组成员设置 / 删除头像 |
| 管理本组成员与可见范围 | `manageMembers` | **关** | 增删本组成员、调整本组可见白名单 / 黑名单 |

> 未勾选的能力，组长在该小组内**无法使用**——服务端会对每个请求重新校验，不只是界面置灰。

#### 成员

- 顶部有成员搜索框，右侧显示 `已选 N 名成员、M 名组长`；
- 勾选成员即加入小组；成员行右侧的「组长」按钮用于任命 / 取消组长，**必须先成为成员**；
- 取消成员资格会**同时取消其组长身份**；
- 还没有任何成员时提示「还没有成员，请先到「成员」页添加」。

#### 可见范围

两个文本域，**每行一个相对网盘根目录的路径**（例如 `项目A`、`公共资料/2026`）：

| 字段 | 说明 |
|:-------------- |:--------------------------------------- |
| 白名单 | 留空表示**不限制**；填了则成员在该小组下只能看到这些目录及其子目录 |
| 黑名单 | **优先级高于白名单**，同时命中时一律隐藏；不可见的目录对成员表现为「不存在」（列表里没有、直接访问返回 404） |

路径会被清洗：去掉首尾 `/`、把 `\` 统一成 `/`、丢弃空串与任何含 `..` 的段，最多保留 200 条。
隐藏不只作用于浏览：**打包下载与在线压缩也会递归跳过不可见的子目录**，不会从压缩包里漏出去。

#### 权限

19 个权限开关按四组排列（键名与「权限」页的 `memberPerms` 完全一致）：

| 分组 | 开关 |
|:------------------ |:--------------------------------------------------------------------- |
| **文件操作** | 文件操作总开关（`fileWrite`）、上传文件、上传文件夹、新建文件夹、复制、移动、重命名、删除 |
| **浏览、下载与预览** | 浏览目录、下载文件、下载文件夹（打包）、允许预览 |
| **高级功能** | 压缩 Zip、解压 Zip、多线程下载器、HTML 全屏预览、在线编辑 |
| **管理与账户** | 管理访客可见性、修改密码 |

- 这里的开关**只能在「权限」页设定的全局成员权限基础上继续关闭**，无法放开全局已关闭的项
  （服务端把两者取"与"，见 [权限与角色](权限与角色.md#3-小组权限收窄与可见范围)）；
- 关闭「文件操作总开关」时，上传文件 / 上传文件夹 / 新建文件夹 / 复制 / 移动 / 重命名 / 删除
  会**一起变灰**，因为它们在服务端本来就不生效；
- 改完点对话框底部「保存」才会提交（新增组标题为「新建小组」，编辑组为「编辑小组 · 组名」）。

### 删除小组

`⋯` →「删除」→ 二次确认，提示写着：小组成员关系与可见范围将一并删除，**该小组的待办会转为全体可见**。

### 数量与归属规则

| 规则 | 值 / 表现 |
|:-------------------------- |:--------------------------------------- |
| 小组数量上限 | **200** 个 |
| 每个小组的成员上限 | **500** 人（组长最多 **100** 人） |
| 成员被超管删除 | 自动从所有小组移除，其创建 / 被指派的待办作相应清理 |
| 小组被删除 | 该组待办转为「全体」可见 |
| 超管 | 可切换任意小组；小组的可见范围与权限收窄对**超管不生效** |
| 访客 | 不参与小组机制，仍走「对访客隐藏」那套规则 |

## 权限

这一页分成六块。**改数值后别忘了点该块的「保存」**。

### 1. 上传大小限制（单文件 MB）

| 输入框 | 配置字段 | 默认 |
|:-------------- |:---------------------- |:-------- |
| 超级管理员 | `superUploadLimitMB` | 2048 |
| 团队成员 | `memberUploadLimitMB` | 512 |

### 2. ZIP 打包 / 解压限制

| 输入框 | 配置字段 | 默认 | 作用范围 |
|:-------------- |:------------------- |:-------- |:-------------------------------- |
| 最大文件数 | `zipMaxFiles` | 100 | 打包下载与在线压缩的条目数；解压时限压缩包内条目数 |
| 单文件最大 | `zipMaxSingleMB` | 50 | 打包时被选中文件的上限；解压时单个条目的上限 |
| 总大小最大 | `zipMaxTotalMB` | 128 | 打包的总量上限 |
| 解压 ZIP 最大 | `extractMaxZipMB` | 128 | 被解压的 `.zip` 文件本身体积上限 |

> 「解压后总量最大」不在这里，在**安全**标签页。

### 3. 链接下载工具限制（单个文件 MB）

| 输入框 | 配置字段 | 默认 |
|:-------------- |:------------------- |:-------- |
| 单个文件最大 | `downloadUrlMaxMB` | 4096 |

### 4. 团队成员权限

按分组排列，全部是即时保存的开关：

- **文件操作**（总开关 `fileWrite`）
  - 子项：上传文件、上传文件夹、新建文件夹、复制、移动、重命名、删除
  - 总开关关闭时子项整体变灰且失效（原因见 [权限与角色](权限与角色.md) 的「权限之间的依赖关系」一节）
- **下载与预览**：浏览目录、下载文件、下载文件夹、允许预览
- **高级功能**：压缩为 Zip、解压 Zip、多线程下载器、HTML 全屏预览、在线编辑文件
- **管理与账户**：管理访客可见性、修改密码

### 5. 访客权限

浏览目录、下载文件、下载文件夹、允许预览、压缩为 Zip、解压 Zip、HTML 全屏预览、在线编辑文件。

### 6. 对访客隐藏的文件夹

列出当前所有被隐藏的路径（显示成 `/路径`），点「恢复可见」即可取消。
列表为空时提示"在文件列表中右键文件夹可设为隐藏"。

## 数据与保留

这一页管四件事：**头像**、**团队待办**、**默认上下文可见范围**、**日志与指标保留**，
最后是**数据备份与回滚**。开关是即时保存的，带输入框的项目必须点各自的「保存」。

### 头像

| 项目 | 配置字段 | 默认 | 说明 |
|:---------------------------- |:-------------- |:-------- |:--------------------------------------- |
| 允许成员设置头像 | `avatarEnabled` | **开** | 关闭后成员与超管都无法上传 / 修改头像 |
| 单张体积上限 | `avatarMaxKB` | `200` KB | 取值 1–10240；只影响服务端接受的体积，不改变图片尺寸 |

头像统一是 **128×128 的 WebP**：浏览器端先把选中的图片居中裁切缩放到 128×128 再上传，
服务端同样会校验格式与尺寸（不是 128×128 直接拒绝），并按 `avatarMaxKB` 限制体积。
接口只回传 `md5`，前端用 IndexedDB 缓存，**没换过头像就不会重复下载**。

可以在这些地方看到头像：顶栏右上角、成员表格、「小组」对话框的成员列表、「团队待办」的作者与成员标签。
超管可以为任意账户设置头像；组长需要所在小组开启「修改本组成员头像」才能改本组成员的头像。

### 团队待办

| 项目 | 配置字段 | 默认 | 说明 |
|:------------------ |:-------------- |:-------- |:--------------------------------------- |
| 启用团队待办 | `todoEnabled` | **开** | 关闭后所有成员都看不到待办，创建请求会被拒绝（返回「Todo 功能已关闭」） |

功能本身的用法见 [使用手册 · 团队待办](使用手册.md#14-团队待办)，接口见 [API 参考](API参考.md#5-团队待办-apitodos)。

### 默认上下文可见范围

给**不属于任何小组、或顶栏选择「默认」**的成员设定可见范围，字段是
`defaultVisibility`（`{ whitelist, blacklist }`），规则与小组的可见范围完全一致：
白名单留空表示不限制，黑名单优先，不可见的目录对成员表现为「不存在」。
超管与访客不受它影响。改完点「保存」。

### 日志与指标保留

| 项目 | 配置字段 | 默认 | 取值范围 | 说明 |
|:------------------ |:------------------------ |:-------- |:--------------- |:--------------------------------------- |
| 采集请求指标 | `requestMetricsEnabled` | **开** | 开 / 关 | 统计 QPS、状态码分布与慢请求；关闭后指标卡片显示 `—` |
| 日志保留 | `logRetentionDays` | `30` | 1–3650 | 日志文件保留天数 |
| 指标落盘保留 | `metricsRetentionDays` | `7` | 1–365 | `data/metrics/` 下采样文件的保留天数 |
| 内存曲线窗口 | `metricsMemMinutes` | `15` | 1–1440 | 内存里保留的采样窗口（分钟），也是请求指标的统计窗口 |
| 慢请求阈值 | `slowRequestMs` | `1000` | 1–600000 | 耗时达到该值的请求计入「慢请求」（毫秒） |

> 这一页没有「是否启用数据备份」的开关：`backupEnabled` 默认 `true`，只能手工编辑
> `data/config.json`（或在 `PATCH /api/admin/config` 里传该字段）来关闭。

### 数据备份与回滚

- 「立即备份」按钮对受管数据文件做一次快照（返回创建了几份）；
- 服务端还会**在每次覆盖写入前自动快照旧内容**，并**每天**做一次全量快照；
- 备份保存在 `data/backups/<文件名>/<时间戳>.json`，**每个文件保留 `backupKeep` 份（默认 20，1–500）**，
  超出后**删除最旧的**快照；
- 只覆盖四个数据文件：`config.json`（系统配置）、`users.json`（成员账户）、`groups.json`（小组）、
  `todos.json`（团队待办）——**网盘文件本身不在备份范围内**；
- 表格列出 文件 / 时间 / 大小，点「回滚」→ 确认框 → 用该快照覆盖当前文件；
  **回滚前会先把当前状态自动快照一份**，改错了还能再退回来；回滚后建议刷新页面。

## 安全

### 接口限流

| 项目 | 说明 |
|:-------------- |:--------------------------------------- |
| 开启限流 | 总开关（`rateLimitEnabled`），默认**开** |
| 每分钟上限 | 单 IP 每分钟允许的"重型操作"次数（`rateLimitPerMin`），默认 **120** |

**受限的接口**：打包下载、在线压缩、在线解压、递归搜索、查看详情、链接下载。
**不受限的接口**：普通列目录、单文件下载——因为画廊预览、连续下载这类正常使用会产生大量请求。

超限时返回 429「操作过于频繁，请 N 秒后再试」，并带上 `Retry-After` 头。

### 解压保护

| 项目 | 说明 |
|:-------------- |:--------------------------------------- |
| 解压总量最大 | `extractMaxTotalMB`，默认 **512 MB** |

超出时会**中止解压并清理已写出的内容**，避免用一个小压缩包把磁盘占满。
（先按压缩包头声明的大小快速拒绝，解压过程中再按实际写出的字节累计复核。）

### 其他安全开关

| 开关 | 配置字段 | 默认 | 关闭后会怎样 |
|:-------------------------------- |:-------------------------- |:-------- |:--------------------------------------- |
| 允许复制只读映射目录的内容 | `softDirAllowCopyOut` | **关** | 关闭时，只读映射目录里的内容**不能**复制 / 压缩进网盘目录 |
| 作业进度仅创建者可见 | `jobStatusOwnerOnly` | **开** | 关闭后，团队成员之间可以互相看到压缩 / 解压 / 链接下载任务的文件名与进度 |
| 链接下载允许访问内网地址 | `downloadUrlAllowPrivate` | **关** | 关闭时禁止链接下载工具抓取内网 / 回环 / 链路本地 / 云元数据地址；等效于 `.env` 的 `DOWNLOAD_URL_ALLOW_PRIVATE` |
| 写操作校验请求来源 | `csrfOriginCheck` | **开** | 关闭后不再校验 `Origin` / `Sec-Fetch-Site`（仍保留自定义请求头校验）。**反向代理改写了 Host 头导致写操作被误拦时**才需要关 |

> 「允许复制只读映射目录的内容」默认关闭是有原因的：如果你把项目根目录之类的位置映射进来，
> 低权限成员本来可以顺手把 `.env`、`data/.jwt-secret` 复制到一个公开目录再下载走。

### 客户端 IP 解析

这一块只**显示**当前状态（徽章上写着"直连（不信任代理头）"或"信任代理头 xxx"），**不能在这里改**。
它由服务端 `.env` 的 `TRUST_PROXY` 决定，改动后需要**重启服务**。

- 只通过隧道 / 反向代理访问时设为 `loopback`，日志与按 IP 限速才会用真实客户端 IP；
- 如果服务**同时能被直接访问**，请保持关闭，否则客户端可以伪造该请求头绕过限速。

详细取值与取舍见 [公网访问与隧道](公网访问与隧道.md#4-trust_proxy-该怎么填)。

## 公网

### SSH 反向隧道

| 控件 | 说明 |
|:------------------ |:--------------------------------------- |
| 启用公网访问 | 总开关。打开后立刻尝试建立隧道 |
| 隧道服务 | `pinggy.io（推荐）` / `localhost.run` / `serveo.net` / `自定义 SSH` |
| SSH 目标 | **仅在选择「自定义 SSH」时出现**，格式 `user@host` 或 `user@host:端口`；需要本机已配置免密 SSH 密钥 |
| 应用并重连 | 仅隧道已启用时出现，用于按当前配置重连 |

**切换「隧道服务」时，如果隧道正在运行，会立刻按新模式重连。**

### 运行状态

- 徽章：`运行中` / `未运行`
- 公网地址：抓到后显示在只读输入框里，点一下可全选复制
- 重连次数：自动重连过多少次（没重连过时显示"隧道日志"）
- 输出区：隧道进程最近 40 行输出（含实际执行的 `ssh` 命令）

隧道断开后会自动重连，退避从 5 秒开始逐次翻倍，最长 60 秒一轮。

> 隧道需要服务端能执行 `ssh` 命令。如果没有安装 SSH 客户端，输出区会提示
> `错误: 未检测到 SSH 客户端，请先安装 OpenSSH Client`，并给出 Windows 的安装路径提示。

完整的隧道模式对照、`ssh` 参数与排查方法见 [公网访问与隧道](公网访问与隧道.md)。
