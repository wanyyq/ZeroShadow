对应版本：**v2.0.0-beta**。三种类型都已可用：`theme`（声明式 CSS）、`fileType`（沙箱 iframe）、
`server`（独立子进程 + actions 白名单）。

## 它是什么

插件是**一个 zip 包**，里面必须有 `manifest.json`：

```text
my-theme.zip
├── manifest.json        # 必需，唯一入口
└── （主题插件不需要其它文件）
```

管理员在「设置 → 插件」上传 zip → 服务端校验 → 装进 `data/plugins/<id>/` →
**默认禁用**（要手动启用）→ 主题插件还要再点「应用主题」。

<Callout type="warn" title="两扇默认关着的门">
插件总开关 `pluginsEnabled` **默认关闭**：关着的时候安装接口直接 **403**。
装完之后插件也是**默认禁用**的。插件是第三方内容，必须由管理员显式打开。
</Callout>

## manifest.json

```json
{
  "id": "org.example.solarized",
  "name": "Solarized 主题",
  "version": "1.0.0",
  "apiVersion": 1,
  "kind": "theme",
  "description": "低饱和的暖色主题",
  "author": "example",
  "homepage": "https://example.org/solarized",
  "theme": {
    "light": { "--background": "oklch(0.98 0.01 90)" },
    "dark": { "--background": "oklch(0.22 0.02 220)" },
    "fontSans": "'Google Sans Flex', system-ui, sans-serif"
  },
  "settings": {
    "type": "object",
    "additionalProperties": false,
    "properties": {
      "accent": { "type": "string", "title": "主色", "enum": ["auto", "blue"], "default": "auto" },
      "compact": { "type": "boolean", "title": "紧凑模式", "default": false },
      "size": { "type": "integer", "title": "字号", "minimum": 12, "maximum": 20, "default": 16 }
    }
  }
}
```

| 字段 | 必填 | 约束 |
|:--|:--|:--|
| `id` | ✅ | `^[a-z0-9][a-z0-9-]*(\.[a-z0-9-]+){1,5}$`，全局唯一 |
| `name` | ✅ | ≤ 40 字符 |
| `version` | ✅ | `x.y.z`（可带 prerelease） |
| `apiVersion` | ✅ | 目前**只接受 `1`** |
| `kind` | ✅ | `theme` / `fileType` / `server` |
| `permissions` | | 白名单 `fs.read` `fs.write` `ui.toast` `settings.rw`；**`theme` 必须为空** |
| `theme` | kind=theme | 见下 |
| `settings` | | JSON Schema 子集 |
| `entry` | kind≠theme | 包内相对路径，不能含 `..` |

<Callout type="info" title="未知字段会直接导致安装失败">
这是有意的：宁可装不上，也不要"某个字段被静默忽略、作者以为生效了"。
</Callout>

## 主题插件

`theme` 只接受**声明式 CSS 变量**，不接受任何 JS，因此零执行风险。

- `theme.light` / `theme.dark`：键必须是 `--` 开头的自定义属性（每个 ≤ 80 个）；
- `theme.fontSans`：可选字体栈，作用到 `body`；
- **值的约束**：≤ 200 字符，禁止 `;` `{` `}` `@` `<` `>` `\`、换行，以及 `url(` / `expression(` / `javascript:`。
  原因：这些值会被拼进一条 CSS 规则，能"逃出规则"就能改掉整页样式，`url()` 甚至能引出远程请求。

应用方式：服务端把令牌拼成 `html[data-theme-plugin="<id>"]` 作用域的 CSS，前端注入 `<style>`。

## 权限白名单

| 权限 | 含义 | 状态 |
|:--|:--|:--|
| `fs.read` | 读取当前用户可见的文件 | 保留，随 `fileType` 运行时启用 |
| `fs.write` | 保存文件（仍受 `fileWrite` + `editFiles` 约束） | 同上 |
| `ui.toast` | 由宿主弹提示 | 同上 |
| `settings.rw` | 读写插件自己的设置 | 已可用 |

设计底线：**插件永远不直接访问 `/api`**。`fileType` 插件将来跑在
`sandbox="allow-scripts"`（**无** `allow-same-origin`）的 iframe 里，靠 `postMessage` 请求宿主代执行，
宿主照常走 `req.perms`。插件的能力上限 = 当前登录用户的权限。

## 设置项（JSON Schema 子集）

声明 `settings` 后，后台「设置 → 插件 → 设置」会自动渲染表单：

- `type: "object"` + **扁平** `properties`（≤ 20 项），`additionalProperties` 只能 `false`；
- 属性 `type` ∈ `string` / `number` / `integer` / `boolean`；
- `string` 可带 `enum`、`maxLength`、`default`、`placeholder`；数字可带 `minimum` / `maximum`；
- 可选的 `title` / `description` 用于展示。

服务端保存时**按 schema 再校验一遍**（越界 / 非枚举 / 类型不符都 400），并且只保留声明过的键。

### `public`：设置项要不要下发到浏览器

默认**不下发**。`GET /api/plugins/list` 匿名可访问（访客也要能预览），而设置项最自然的用途
就是放 API key / webhook 地址——全量下发等于把管理员填的密钥公开给任何访客。

需要让插件在前端读到某一项时，给该项标 `"public": true`：

```json
"settings": {
  "type": "object",
  "additionalProperties": false,
  "properties": {
    "accent": { "type": "string", "title": "主色", "enum": ["auto", "blue"], "public": true },
    "apiKey": { "type": "string", "title": "API Key" }
  }
}
```

标了才会出现在 `/api/plugins/list` 的 `settings` 与 `init.settings` 里；没标的只在服务端
`data/plugins.json`。只下发字符串/数字/布尔标量。

## 接口

```text
GET    /api/admin/plugins                    列出 + 总开关状态
POST   /api/admin/plugins?filename=x.zip     安装（body 为 zip 原始字节，Content-Type: application/zip）
PATCH  /api/admin/plugins/:id                { enabled?, settings? }
POST   /api/admin/plugins/:id/theme          { active: true }
DELETE /api/admin/plugins/:id                卸载
GET    /api/plugins/theme                    公开：当前主题 CSS
GET    /api/plugins/list                     公开：已启用的 fileType 插件（id/name/version/kind/extensions/modes/permissions
                                              + 仅标了 public:true 的 settings）
GET    /api/plugins/entry/:id                插件入口 HTML（响应带 sandbox + connect-src 'none' 的 CSP）
POST   /api/admin/plugins/:id/action         server 插件：{ action, params } → { ok, data }
```

> 总开关 `pluginsEnabled` 关掉时，最后三条**公开**接口也一并停用：`/theme` 返回空 CSS、
> `/list` 返回空数组、`/entry/:id` 返回 404。这样"关闭插件"才是真正的应急手段。

## 文件类型插件（沙箱 iframe）

`kind: "fileType"` 负责内置渲染器不认识的格式。约束四条：`entry` 必须是**单个自包含 `.html`**、
iframe 用 `sandbox="allow-scripts"`（无 `allow-same-origin`）、入口响应 CSP 为
`default-src 'none'` + `connect-src 'none'`、宿主同时校验 `event.source === contentWindow`
**与** `event.origin === "null"`（不透明源的 origin 序列化后就是字符串 `"null"`，因此这个值
是可用来校验的；插件把自己导航到外部站点后 origin 变成真实源，消息会被丢弃并断链）。

<Callout type="warn" title="残余风险：带 fs.read 的插件只装可信的">
CSP 没有 `navigate-to`、sandbox 也不禁止帧自我导航，所以持 `fs.read` 的插件理论上能把读到的
内容拼进 `location.href` 带出去。宿主已把**导航之后的协议**掐断（origin 校验 + 入口文档
再次 load 即断链），不让一次导航升级成"任意文件读取接口"，但已经读到的内容拦不住。
</Callout>

协议（`apiVersion: 1`）：

```text
plugin → host   { type: "zs:ready" }
host   → plugin { type: "zs:init", apiVersion, file, settings, canWrite, dark }
plugin → host   { type: "zs:request", id, method, params }     // readText | readBinary | saveText | notify
host   → plugin { type: "zs:response", id, ok, result?, error? }
plugin → host   { type: "zs:dirty", dirty: boolean }
```

`saveText` 带最近一次读到的 `baseVersion`，文件被改过时服务端 409、宿主原样回报，**不会静默覆盖**。

## 服务端插件（独立子进程）

先说结论：**这不是安全沙箱，是故障隔离**。子进程与主进程同一个操作系统用户，等于
"在服务器上以该用户身份执行任意程序"——可以直接读 `.env`（超管明文口令）与
`data/.jwt-secret`（会话签名密钥，拿到即可伪造任意成员登录），只装可信插件。
收敛手段：环境变量白名单（不含 `JWT_SECRET`）、只转发 `actions` 里声明的动作、
单动作 5 秒超时（超时**杀进程**）、启动 10 秒超时、单行输出 256 KB 上限、空闲 60 秒回收、
禁用/卸载/服务退出都会先 `shutdown` 再杀。

```text
host   → plugin  {"type":"init","apiVersion":1,"settings":{}}
plugin → host    {"type":"ready"}
host   → plugin  {"type":"action","id":1,"action":"rebuild","params":{}}
plugin → host    {"type":"result","id":1,"ok":true,"data":{}}
```

失败语义：未启用 400、动作未声明 400、超时 504、进程启动失败 502。
调试信息请写 stderr（宿主保留最近 20 行），stdout 只应输出 JSON 行。

## 自测清单

- [ ] 总开关关闭时安装返回 403
- [ ] 装完列表里 `enabled: false`
- [ ] 未启用就应用主题返回 400
- [ ] 应用后 `/api/plugins/theme` 的 CSS 含 `data-theme-plugin` 与自己的变量
- [ ] 设置越界值返回 400
- [ ] 卸载后主题自动恢复默认
- [ ] fileType：未启用时不在 `/api/plugins/list`、入口 404；启用后入口 CSP 含 `sandbox allow-scripts`
- [ ] fileType：`entry` 写 `.js` 或缺 `extensions` 安装被拒
- [ ] server：未启用 400、未声明动作 400、超时 504 且随后能重新拉起、禁用 400 / 卸载 404

## 已知边界

- 服务端插件**不是安全沙箱**：同用户进程，只装可信插件；
- 同一时间只能有一个主题生效；
- 插件不能加自己的路由、不能直连网络；
- 插件**不会**自动更新：更新意味着权限可能变化，必须由管理员重新确认。
