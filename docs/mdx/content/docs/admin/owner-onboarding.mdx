**读者**：已经把 ZeroShadow 跑起来、手里有超管密码的人。
**目标**：30 分钟内完成「安全基线 + 团队接入」，并且知道日常该看哪里。
**不覆盖**：装 Node、配 HTTPS 证书、从发布包启动 → 见 [快速开始](/docs/zeroshadow/getting-started/quickstart)。

本文只写**管理动作**，每条都给出「点哪里」和「为什么」。所有数值都是**首次运行**（`data/config.json` 还不存在时）的默认值，后台改过之后以实际值为准。

## 先记住三件事

### 只有三种角色

| 角色 | 怎么来 | 能做什么 | 不能做什么 |
|:--|:--|:--|:--|
| **超级管理员** | `.env` 的 `SUPER_ADMIN_USER`（全局唯一，默认 `admin`） | 全部：成员、小组、权限、分享、备份、日志、隧道、WebDAV、插件 | 密码**不能**在后台改（只能改 `.env` 重启）；**不能**用作 WebDAV 账号 |
| **团队成员** | 超管在「成员」页创建 | 在你给的权限范围内操作文件、预览、在线编辑、分享、待办 | 进不了服务器管理（设置页除「外观」外的标签都看不到） |
| **访客** | 未登录，直接打开地址 | 默认只有「浏览 / 下载文件 / 下载文件夹 / 预览」四项 | 上传、编辑、压缩、解压、改密码、分享 —— 一律不行 |

### 超管密码只存在 `.env` 里

`SUPER_ADMIN_PASSWORD`，明文。改密码 = 编辑 `.env` + **重启服务**。重启后旧会话全部失效，这是有意的（口令版本参与会话校验），不是 bug。

### 设置页有 12 个标签

外观 / 状态 / 日志与指标 / 成员 / 小组 / 分享 / 权限 / 数据与保留 / 回收站 / 安全 / 公网 / 插件。除「外观」外都只有超管能看见 —— 成员登录后在设置里只能改自己的外观偏好。

## 首次登录（约 3 分钟）

1. 浏览器打开 `http://<服务器IP>:<端口>`。端口默认 **12345**，以 `.env` 的 `PORT` 为准；只在本机试就用 `http://127.0.0.1:12345`。
2. 用户名 = `.env` 的 `SUPER_ADMIN_USER`（默认 `admin`）；密码 = `.env` 的 `SUPER_ADMIN_PASSWORD`。
3. **找不到密码**：如果 `.env` 里原本没写密码，服务首次启动会随机生成一个，**打印在控制台**（那段 `[重要] 已自动生成超级管理员密码…`）并同时写回 `.env`。直接打开 `.env` 抄也一样。
4. **登录后第一件事：改掉这个密码** —— 编辑 `.env` 的 `SUPER_ADMIN_PASSWORD`，保存，重启服务，再用新密码登录。

<Callout type="warn" title="为什么必须重启">
密码改动不会热加载。重启还有个附带好处 —— 之前所有会话令牌同时作废。
</Callout>

## 安全基线（约 10 分钟，按顺序做）

### 第 1 步：改掉自动生成的超管密码

见上一节第 4 步。顺便把 `.env` 备份到密码管理器 —— 丢了它就只能停服务改文件。

### 第 2 步：决定访客能看到什么

**位置**：设置 → **权限** → 访客权限。首次运行的默认值：

| 访客权限 | 默认 | 说明 |
|:--|:--|:--|
| 浏览目录 / 下载文件 / 下载文件夹 / 允许预览 | **开** | 内网共享的基本盘 |
| HTML 全屏预览 | **关** | 上传的 `.html` 不在网盘源里执行脚本，但预览仍会渲染页面 |
| 在线编辑文件 / 压缩为 Zip / 解压 Zip | **关** | 这三项会产生**真实写入** |
| 删除、重命名、移动、新建等写权限 | 无 | 访客没有「文件操作总开关」这个权限位，`fileWrite` 恒为 false |

还有一道独立的开关：**访客写权限**（`guestWrite`，默认**关**）。它是上面三项写类子权限的**总闸** —— 关着时，即使你勾了「在线编辑文件」，访客也编辑不了。项目刻意这样设计：「允许匿名访客改文件」必须是单独一次明确决定，而不是顺手勾了个看起来无害的子项。

<Callout type="info" title="建议">
内网自用可以保留默认；只要这个地址能被公网访问（隧道、端口映射、公司外网），就把四项默认开的也关掉，只留「浏览」或干脆全关。
</Callout>

### 第 3 步：把不该给访客看的目录藏起来

**两个入口**，效果一样：

- 文件列表里**右键文件夹** → 「对访客隐藏」；
- 设置 → **权限** → 「对访客隐藏的文件夹」→「选择目录」。

要点：

- 隐藏**只约束访客**。团队成员照常可见 —— 想让某些成员看不见，要用小组的「可见范围」。
- 隐藏目录**不能被分享成无密码链接**：创建分享时服务端会按同一套规则判定，要求必须设密码。
- 判定用的是**规范化后的路径**，不是文件名字符串 —— 换大小写、用 8.3 短名、绕符号链接都进不来（这条在 2.0.0-beta 的安全修复里专门加固过）。

### 第 4 步：关掉用不到的功能

用不到的功能就是白送的风险。下表都是默认值，按需关闭：

| 功能 | 默认 | 在哪关 | 关掉之后 |
|:--|:--|:--|:--|
| 公网隧道 | 关 | 设置 → 公网 → 启用公网访问 | 不拉 ssh，公网不可达 |
| WebDAV | 关 | 设置 → 公网 → WebDAV | `/dav` 直接 404 |
| 插件 | 关 | 设置 → 插件 → 启用插件功能 | 装不了；关掉后已装插件也不再生效（文件保留） |
| 分享链接 | 开 | 设置 → 分享 → 启用分享功能 | 既有链接一律失效，也建不了新的 |
| 匿名访问分享 | 开 | 设置 → 分享 → 允许匿名访问分享链接 | 打开分享链接必须先登录网盘账号 |
| 团队待办 | 开 | 设置 → 数据与保留 → 启用团队待办 | 「团队」页对所有成员不可用 |
| 头像 | 开 | 设置 → 数据与保留 → 头像 | 成员与超管都不能再改头像 |
| 链接下载访问内网 | 关 | 设置 → 安全 → 链接下载允许访问内网地址 | 保持关闭即可挡住 SSRF |

### 第 5 步：限流别关

**位置**：设置 → 安全 → 接口限流。默认开启，**120 次/分钟/IP**，可在同一页调数值或整体关闭。

它只作用于单次代价高的接口：打包下载、在线压缩、在线解压、递归搜索、看目录详情、链接下载。**普通浏览目录与单文件下载不受影响**，不要因为"怕影响同事"就把它关掉 —— 关掉它不会让谁更快，只会让一台机器能拖垮全站。

### 第 6 步：要放到公网，先把这两件事做对

1. **上 HTTPS**（Caddy / Nginx / 隧道自带的 https 都行）。本服务自身不监听 TLS，明文暴露会让超管密码和 WebDAV 凭据反复裸奔。
2. **再配 `TRUST_PROXY`**，而且**只在「服务仅经该代理访问」时**开（例如只通过 SSH 隧道）。开了它，客户端 IP 取自 `X-Forwarded-For`，而这个头是请求方可控的 —— 如果你同时又允许直连，攻击者可以伪造 IP 绕过限流、污染日志。

详细取值（`true` / 跳数 / `loopback` / 网段列表）与排查见 [公网访问与隧道](/docs/zeroshadow/admin/tunnel)。

## 把团队接进来（约 10 分钟）

### 建成员

**位置**：设置 → **成员** → 「添加成员」。

- **单个 / 批量**都走同一个对话框：每行一个账户，格式「用户名 密码」，**省略密码就自动生成**。
- 用户名 **2–32 位**（字母、数字、`_`、`.`、`-`），密码**至少 6 位**。
- 创建成功后账号密码**只展示这一次**，记得当场复制发人。
- 后续操作都在成员行的操作菜单里：**重置密码 / 更改用户名 / 设置头像 / 删除**。删除是永久的（不可撤销，也不进回收站）。
- 成员被**删除或禁用**后，他手上已有的会话立即失效（不需要等 72 小时过期）。

### 建小组（可选，但强烈推荐）

**位置**：设置 → **小组** → 「新建小组」。对话框四个页签：**基本 / 成员 / 可见范围 / 权限**。

记住一条规则：**小组只做「收窄」** —— 可见范围与权限都只能在超管设定的全局范围内收紧，永远不会放宽。所以你可以放心把小组交给组长。

- **可见范围**：白名单为空表示不限制；黑名单里的路径一律隐藏（黑名单优先）。
- **组长权限**默认一项都不给，可按需下放四项：查看本组成员名单 / 创建·编辑本组待办 / 修改本组成员头像 / 管理本组成员与可见范围。
- 成员可以属于多个小组；**顶栏切换当前小组**后，可见范围、权限、待办都随之收窄。

### 定权限基线

**位置**：设置 → **权限** → 团队成员权限。共 **20 个权限点**，分四组：

| 分组 | 权限点 | 默认 |
|:--|:--|:--|
| 文件操作 | **文件操作总开关**、上传文件、上传文件夹、新建文件夹、移动 | 全开 |
| 下载与预览 | 浏览目录、下载文件、下载文件夹、允许预览 | 全开 |
| 高级功能 | 压缩为 Zip、解压 Zip、文件转换、多线程下载器、HTML 全屏预览、在线编辑文件、复制、重命名、删除 | 全开 |
| 管理与账户 | 管理访客可见性、修改密码 | 全开 |

几个容易漏掉的**依赖关系**：

- 「文件操作」是**总开关**：关掉它，上传 / 新建 / 移动 / 转换等写类权限全部失效（小组里也是这样）。
- 在线编辑要「在线编辑文件」；`.html` 要全屏预览还要「HTML 全屏预览」。
- 文件转换除了「文件转换」这个开关，还要对源文件有读权限（「允许预览」或「下载文件」之一）；**访客永远不能转换**（后台也没有这个开关）。
- 分享会校验**下载权限**：没有「下载文件 / 下载文件夹」的成员不能把内容分享出去（否则关了下载权限也能"分享给自己再下载"）。
- 隐藏访客可见目录要「管理访客可见性」（默认开，成员因此也能右键隐藏目录）。

同一页还有三组上限（都是单文件/单次，不是配额）：

| 上限 | 超管 | 成员 |
|:--|--:|--:|
| 上传大小 | **2048 MB** | **512 MB** |
| ZIP 打包：文件数 / 单文件 / 总量 | 100 个 / 50 MB / 128 MB | 同左（全局） |
| 解压：ZIP 本体 / 解压后总量 | 128 MB / 512 MB | 同左（全局） |
| 链接下载器单个文件 | 4096 MB | 同左（全局） |
| 文件转换：Markdown / 图片 | 4 MB / 32 MB | 同左（全局） |

<Callout type="info" title="在线编辑是另一套上限">
读取 **8 MB** / 保存 **16 MB**，与上面的上传上限无关。
</Callout>

## 日常运维：其实只有四个地方

| 你要看的 | 位置 | 关键点 |
|:--|:--|:--|
| 服务是否健康 | 设置 → **状态** | 在线人数、磁盘、版本、运行时长 |
| 出问题查什么 | 设置 → **日志与指标** | 打开「仅审计事件」只看登录、权限变更、成员/小组变更、文件写操作、备份回滚、隧道开关；可导出 CSV / JSONL（CSV 带 BOM，Excel 直接打开不乱码） |
| 改坏了怎么回滚 | 设置 → **数据与保留** → 数据备份与回滚 | 覆盖写入前自动快照 + 每日一次快照，每个文件保留 **20 份**；受管 **6 个**文件：`config.json` / `users.json` / `groups.json` / `todos.json` / `shares.json` / `plugins.json`。回滚前会先给当前状态再拍一份，可以反悔 |
| 误删了怎么找回 | 设置 → **回收站** | 默认开启、保留 **30 天**；删除先进回收站；**覆盖类操作也会进回收站**（包括 WebDAV 的 PUT 覆盖）。回收站目录不可用（磁盘满/只读）时，界面会明确告警"删除会直接生效" |

<Callout type="warn" title="没有磁盘配额">
只有单文件上限。长期跑要注意 `data/` 与 `FILES_DIR` 所在卷的空间 —— 回收站、日志、备份、缩略图都在这块盘上。
</Callout>

## 按需开启的四件事（想清楚再开）

| 能力 | 打开位置 | 开之前必须知道 |
|:--|:--|:--|
| **WebDAV** | 设置 → 公网 → WebDAV | 只支持 **HTTP Basic**：用户名密码**每个请求都会重发**，所以只在 HTTPS 或完全可信的内网用；**不接受超管账号**（只用成员）；覆盖已有文件需要「删除」权限且旧内容进回收站 |
| **公网隧道** | 设置 → 公网 → SSH 反向隧道 | 支持 pinggy / localhost.run / serveo / 自定义 SSH，掉线自动重连。开了之后记得按第 6 步配 `TRUST_PROXY`，否则日志和限流里全是 `127.0.0.1` |
| **插件** | 设置 → 插件 → 启用插件功能 | 默认关。装完**默认禁用**，要手动启用；主题还要再点一次「应用主题」。**服务端插件不是沙箱**（与主进程同一操作系统用户，能读到 `.env` 与 `data/.jwt-secret`）→ 只装可信来源。插件配置项只有标了 `public` 的才会下发到浏览器 |
| **链接下载器抓内网** | 设置 → 安全 → 链接下载允许访问内网地址 | 默认关。确有需要时优先用 `.env` 的 `DOWNLOAD_URL_ALLOW_HOSTS` 只放开某几台主机，比整片内网放开安全得多 |

## 一页验收清单

复制到你的部署记录里，逐条打勾：

- [ ] 超管密码已改（不是首次自动生成的那个），`.env` 已备份
- [ ] 能说清这个实例**谁能访问**：仅内网 / 经隧道 / 直连公网
- [ ] 访客权限符合预期；公网暴露时已关掉访客的所有写类权限
- [ ] 需要藏的目录已「对访客隐藏」，并**用未登录的浏览器窗口**验证过（不是只自己刷新）
- [ ] 成员账号已建好并发出，要求各人首次登录后改密码
- [ ] 小组与可见范围按团队结构配好（或明确决定先不建小组）
- [ ] 权限基线确认过，尤其是「文件操作总开关」和下载权限
- [ ] 上传上限够用；知道在线编辑是 8 MB / 16 MB 的独立上限
- [ ] 回收站开启，保留天数确认
- [ ] 备份开启，并且**真的试过一次回滚**（找一个不重要的配置文件试）
- [ ] 用不到的功能都关了
- [ ] 若上公网：HTTPS + `TRUST_PROXY` 已配，且日志里看到的客户端 IP 是真实 IP
- [ ] 知道出问题先看「日志与指标」，再看 [常见问题](/docs/zeroshadow/getting-started/faq)

## 常见误配

| 现象 | 原因 | 处理 |
|:--|:--|:--|
| 改了 `.env` 的密码，登录还是老密码 | 没重启服务 | 重启后生效 |
| 明明关了「在线编辑」，访客还在编辑 | 给的是**成员账号**而不是访客 | 成员按 `memberPerms` 判定，访客才按 `guestPerms` |
| 关了访客写权限，勾选子项也没用 | 「访客写权限」是总闸 | 真要开，必须先打开这个总闸 |
| 局域网其他设备打不开 | `HOST` 不是 `0.0.0.0`，或防火墙没放行端口 | 看 `.env` 的 `HOST`；放行 `PORT` |
| 开了隧道，日志里全是 `127.0.0.1` | 没配 `TRUST_PROXY` | 见第 6 步；只在服务仅经代理访问时开 |
| 上传大文件被拒 | 超过「上传大小限制」，或反代有自己的 body 上限 | 设置 → 权限 调上限；同时改反代的 `client_max_body_size` |
| 分享链接打不开 | 「启用分享功能」关了，或「允许匿名访问」关了而对方未登录 | 设置 → 分享 两个开关 |
| 压缩 / 解压突然报 429 | 触发接口限流 | 等一分钟，或调高「每分钟上限」 |
| 插件装了没反应 | 总开关没开 / 插件未启用 / 主题没点「应用主题」 | 三步都做过 |
| 回滚了备份，分享和插件设置没回去 | 旧版界面文案写错过（只写了四个文件），实际备份**包含** `shares.json` 与 `plugins.json` | 2.0.0-beta 已修正文案；六个文件都会回滚 |
