侧边栏进入「设置」。页面标题下有一行说明：超管看到的是"管理外观、服务器、成员与权限"，
其他角色看到的是"个性化浏览体验"。

九个标签页（**除「外观」外都只对超级管理员显示**）：

| 标签页 | 谁能看到 | 一句话说明 |
|:--|:--|:--|
| **外观** | 所有人 | 主题、界面密度、字号、侧边栏默认折叠、背景噪点、减少动画，以及默认视图与排序偏好（只存在你自己的浏览器里） |
| **状态** | 仅超管 | 运行时长、占用、访问地址，每 10 秒自动刷新 |
| **日志与指标** | 仅超管 | 操作日志（可筛选 / 可清空）＋ CPU / 内存 / 磁盘曲线与请求指标 |
| **成员** | 仅超管 | 批量创建团队成员、头像、启用 / 禁用 / 改名 / 重置密码 / 删除 |
| **小组** | 仅超管 | 建小组、分成员与组长、收窄权限、设定可见范围 |
| **权限** | 仅超管 | 上传与打包上限、成员 19 项 / 访客 8 项权限开关、访客隐藏列表 |
| **数据与保留** | 仅超管 | 头像、团队待办、默认可见范围、日志 / 指标保留、备份与回滚 |
| **安全** | 仅超管 | 限流、解压总量上限、四个安全开关、客户端 IP 解析说明 |
| **公网** | 仅超管 | SSH 反向隧道的开启 / 模式选择 / 运行状态与日志 |

<Callout type="warn" title="保存方式不一样">
点开标签页里任何**开关**都是**即时保存**的；带**输入框 + 保存按钮**的项目必须点「保存」才生效。
</Callout>

## 外观

这一页分两张卡片：**外观**（主题与界面）和**文件浏览默认值**（视图与排序）。
每张卡片里的行之间用分隔线隔开，右上角有「恢复默认」，一键把这些偏好还原。

| 卡片 | 区块 | 项目 | 选项 | 默认 |
|:--|:--|:--|:--|:--|
| 外观 | 主题 | 主题 | 浅色 / 深色 / 跟随系统（分段控件） | 跟随系统 |
| 外观 | 界面 | 界面密度 | 舒适 / 紧凑 | 舒适 |
| 外观 | 界面 | 字号 | 小 / 标准 / 大 | 标准 |
| 外观 | 界面 | 默认折叠侧边栏 | 开关（仅影响桌面端，窄屏抽屉不受影响） | 关 |
| 外观 | 界面 | 背景噪点 | 开关 | 开 |
| 外观 | 界面 | 减少动画 | 开关 | 关 |
| 文件浏览默认值 | 视图 | 默认视图 | 列表 / 网格 | 列表 |
| 文件浏览默认值 | 排序 | 排序字段 | 名称 / 大小 / 修改时间 | 名称 |
| 文件浏览默认值 | 排序 | 排序方向 | 升序 / 降序 | 升序 |
| 文件浏览默认值 | 排序 | 文件夹置顶 | 开关 | 开 |

各项的实际效果：

- **界面密度**：紧凑会收紧列表行高与卡片内边距，一屏能放下更多条目；
- **字号**：整体缩放界面文字（改的是根字号 `rem`）；
- **默认折叠侧边栏**：只决定初始状态，之后手动折叠 / 展开同样会被记住；
- **背景噪点**：页面底层的细微噪点纹理，关掉后背景更纯净；
- **减少动画**：关闭列表与页面的 GSAP 入场动画、以及界面过渡效果（系统层面开了「减少动态效果」的用户建议打开）；
- 主题按钮在任意页面也能切换，**按 `D` 键**可在浅色 / 深色之间循环。

这些偏好保存在**你自己浏览器的 `localStorage`**（`zs-client-settings` 与 `zs-theme`），
不写服务器，换台设备需要重新设置。

侧边栏的折叠状态现在也统一存在 `zs-client-settings.sidebarCollapsed`（旧键 `zs-sidebar-collapsed`
会在首次读取时自动迁移，升级后折叠状态不会丢）；小组上下文存在 `zs-group-context`
（值为小组 id 或 `default`）。这几个键都只影响你自己的浏览器。

## 状态

每 10 秒自动拉取一次（数据来自 `GET /api/admin/status`）。

### 六个指标卡

| 卡片 | 含义 |
|:--|:--|
| **运行** | 服务已运行时长，格式如 `3 天 4 小时` / `2 小时 15 分钟` / `8 分钟 12 秒` |
| **存储** | 网盘文件根目录下的文件总占用 |
| **内存** | 当前进程的常驻内存（RSS） |
| **Node** | 服务运行的 Node.js 版本 |
| **文件数** | `N 文件 / M 文件夹`（递归统计） |
| **磁盘** | 文件根目录所在磁盘的可用空间；获取不到时显示「不可用」，不影响其他功能 |

<Callout type="info" title="统计上限与缓存">
存储与文件数的统计**最多扫描 20 万个条目**，结果带有 30 秒缓存；条目极多时会标记为部分统计。
</Callout>

### 局域网访问

列出可用的访问地址，每行有标签与可复制的只读输入框：

- `本机`：`http://localhost:<端口>`
- `局域网`：本机每个非回环 IPv4 地址各一行
- `公网`：**仅当隧道正在运行且已抓到公网地址时出现**

## 日志与指标

这一个标签页把「服务器跑得怎么样」和「谁做了什么」放在一起，数据每 10 秒自动刷新一次。

### 系统指标

数据来自 `GET /api/admin/metrics`，**每分钟采样一次**：

| 卡片 | 含义 |
|:--|:--|
| **CPU** | 两次采样之间的 CPU 使用率（%） |
| **内存** | 系统内存使用率（%）；副标题是 `进程 RSS / 系统总内存` |
| **磁盘** | 文件根目录所在磁盘的可用与总空间；取不到时显示占位符 |
| **文件** | `N 文件 / M 文件夹 · 总占用`（递归统计） |

下方两条迷你折线分别是 **CPU 使用率**与**内存使用率**。内存曲线只在内存里保留最近
`metricsMemMinutes` 分钟（默认 **15**）；落盘样本写入 `data/metrics/zs-YYYY-MM-DD.jsonl`，
按 `metricsRetentionDays` 天轮转（默认 **7** 天），可用
`GET /api/admin/metrics/history?date=YYYY-MM-DD` 回看某一天（最多返回 1440 条）。

### 请求指标

- 顶部五个数字：**QPS**、**2xx**、**4xx**、**5xx**、**慢请求**（后四个是最近一分钟的计数）；
- **慢请求**表格列出最近的方法 / 路径 / 状态码 / 耗时，最多保留 50 条；
- 判定"慢"的阈值是 `slowRequestMs`（默认 **1000** 毫秒）；
- 采集本身可以在「设置 → 数据与保留 → 日志与指标保留 → 采集请求指标」（`requestMetricsEnabled`）里整体关掉。

### 操作日志

- **数据来源**：`data/logs/zs-YYYY-MM-DD.log`，按天一个文件，每行一个 JSON 对象。
- **展示范围**：默认读**最近 5 天**，界面一次最多取 300 条，**最新在最上面**。
  天数可切换 `1 天` / `5 天` / `30 天`（对应接口的 `days` 参数，服务端会夹取到 1–90）。
- **筛选**：级别（全部级别 / 信息 / 警告 / 错误）、**仅审计事件**开关、关键词（在事件名、详情、用户名、IP、角色里匹配），
  回车或点「刷新」重新查询。「审计事件」的完整名单在 `server/src/logger.js` 的 `AUDIT_EVENTS` 里
  （登录、权限变更、成员与小组管理、数据备份与回滚、日志清空、隧道开关这类关键动作）。
- **统计**：筛选条上方一排徽章显示本次结果的 `共 N 条`、信息 / 警告 / 错误各多少条，
  以及出现最多的几个事件名（对应响应里的 `stats.total` / `stats.byLevel` / `stats.topEvents`）。
- **清空**：点「清空」→ 确认框 → 删除日志目录下所有 `.log` 文件（此动作会记一条 `logs_clear` 日志）。
- 表格列：时间 / 事件 / 用户 / IP / 详情；事件名前带盾牌图标的是审计事件。鼠标悬停可以看到被截断的完整内容。
- 日志文件本身按 `logRetentionDays`（默认 **30** 天）自动清理。

### 常见事件名

| 事件 | 含义 |
|:--|:--|
| `server_start` | 服务启动 |
| `trust_proxy` | 启动时打印生效的 `TRUST_PROXY` 模式 |
| `download_url_relaxed` | 启动时提示链接下载的 SSRF 限制被放开 |
| `login_success` / `login_fail` | 登录成功 / 失败（含用户名与 IP） |
| `login_locked` | 某账户因连续失败被临时锁定 |
| `logout` / `password_change` | 退出登录 / 成员修改密码 |
| `mkdir` `upload` `rename` `delete` `copy` `move` `save_file` | 文件写操作 |
| `download` | 单文件下载（内联预览不记录，避免刷屏） |
| `download_zip` | 打包下载 |
| `compress` / `extract` | 在线压缩 / 解压完成 |
| `guest_visibility` | 修改了某个文件夹的访客可见性 |
| `config_update` | 后台设置被修改（详情里是本次改动的 JSON） |
| `members_create` / `members_batch` / `members_reset_password` / `members_rename` | 成员管理动作 |
| `group_create` / `group_update` / `group_delete` | 小组的创建、成员调整、可见范围调整与删除 |
| `avatar_update` / `avatar_delete` | 上传 / 恢复某个头像 |
| `todo_create` / `todo_update` / `todo_done` / `todo_delete` | 团队待办的增删改与完成 |
| `backup_create` / `backup_restore` | 手动快照与回滚 |
| `metrics_start` / `metrics_sample_fail` | 指标采集启动 / 某次采样失败（详情里是采样间隔或错误原因） |
| `unhandled_rejection` / `uncaught_exception` | 进程级兜底捕获的异常（**只记日志、不退出进程**） |
| `logs_clear` | 清空日志 |
| `tunnel_start` / `tunnel_stop` / `tunnel_url` / `tunnel_exit` / `tunnel_error` / `tunnel_enable` / `tunnel_disable` | 隧道相关 |
| `server_error` | 服务端 5xx 错误（含请求方法、路径、错误信息、IP） |

<Callout type="info" title="只写文件、不输出到控制台">
想让服务**只写日志文件、不在控制台输出**（例如作为服务在后台跑）：
在 `.env` 里设 `NOLOG=true`，或者启动时加参数 `-nolog`
（用 pnpm 传参要写成 `pnpm start -- -nolog`）。
</Callout>

## 成员

「团队成员（低级管理员）」这一栏管理所有成员账号。**超管自己不在这里**，也删不掉。

### 添加成员

点「添加成员」打开「批量添加成员」：

- **每行一个账户**，格式为 `用户名 密码`（空格、半角逗号、全角逗号都能分隔）；
- **省略密码会自动生成一个随机密码**；
- 允许的写法示例：

```text
alice 123456
bob
carol pass888
```

- 规则提示：用户名 2–32 位（字母 / 数字 / `_` `.` `-`），密码至少 6 位；
- 一次最多提交 **200** 个，成员总数上限 **500**；
- 创建完成后会在页面上显示「创建成功，请保存账号信息（用户名 密码）」，**这段信息只显示这一次**，请复制保存；
- 失败的条目会逐条弹出错误提示（例如"用户名已存在"、"该用户名已被超级管理员占用"、"本次提交中用户名重复"）。

### 成员表格

列依次是：勾选框 / **头像** / 用户名 / 状态（`正常` 或 `已禁用`）/ 创建时间 / 操作（`⋮`）。

**选中若干人之后**，工具栏会出现：`启用`、`禁用`、`批量重置密码`、`删除`。

**单个成员**点 `⋮` 或**在行上右键**（右键菜单是同一套再加头像相关的入口），可以：

| 操作 | 说明 |
|:--|:--|
| 启用 / 禁用 | 禁用会立刻让其所有登录会话失效（登录会提示"该账户已被禁用"） |
| 更改用户名 | 新名字仍要满足 2–32 位规则，且不能与超管或其他成员重名 |
| 重置密码 | 可手填或点「随机生成」；重置后该成员的所有旧会话立刻失效 |
| 设置头像 | 选一张本地图片，浏览器自动裁成 128×128 WebP 后上传（点列表里那一列的小头像效果相同） |
| 恢复默认头像 | 删除该成员的头像文件，回落到自动生成的默认头像（288 种渐变组合 + 两个字符缩写） |
| 删除 | 二次确认，**不可撤销**；同时会把它从所有小组移除、清掉它的头像、并把指派给它的待办转为全体可见 |

<Callout type="info" title="头像相关的开关在「数据与保留」">
「允许成员设置头像」（`avatarEnabled`）与「单张体积上限」（`avatarMaxKB`）都在
**设置 → 数据与保留 → 头像**里，不在这一页。
</Callout>

## 小组

「小组」标签页管理所有小组。小组给成员提供一层**上下文**：切换小组后，文件可见范围、有效权限与团队待办一起收窄。
它与三种角色不冲突——**小组只能收窄，不能放宽**。

### 列表与新建

- 点右上角「**新建小组**」打开编辑器；列表为空时显示「还没有小组」的空状态；
- 每张小组卡片显示：颜色圆点 + 名称、`N 成员` / `N 组长`、
  可见范围摘要（`白名单 N` / `可见不限`，有黑名单时追加 `· 隐藏 N`）与成员用户名；
- 卡片右上角 `⋮` 里是「编辑小组」与「删除」。删除小组会**一并删除成员关系与可见范围**，
  该小组的待办会**转为全体可见**（不会连待办一起删掉）。
- 在卡片上**右键**还有一份同样的菜单，另加「复制小组名」「复制成员名单」。

### 编辑器（四个标签页）

编辑器的说明写得很直白："小组只做「收窄」：可见范围与权限都只能在超管设定的全局范围内收紧，不会放宽。"

| 标签页 | 内容 |
|:--|:--|
| **基本** | 小组名称（最多 40 字符，支持中英文、数字、空格与 `_ . -`）、小组颜色、以及四项**组长权限**开关 |
| **成员** | 搜索成员，勾选加入小组（右侧会显示 `已选 N 名成员、M 名组长`）；每个成员右侧的「组长」按钮可切换组长身份（**取消成员资格会同时取消其组长身份**） |
| **可见范围** | 白名单与黑名单两个多行文本框，**每行一个相对网盘根目录的路径**（例如 `项目A`、`公共资料/2026`） |
| **权限** | 19 个权限开关（键名与「权限」页的 `memberPerms` 完全一致），分四组：文件操作 / 浏览、下载与预览 / 高级功能 / 管理与账户 |

可见范围规则：

| 项目 | 规则 |
|:--|:--|
| 白名单 | **留空表示不限制**；填了则成员只能看到这些目录及其子目录 |
| 黑名单 | **优先级高于白名单**，同时命中时一律隐藏 |
| 不可见的表现 | 对成员表现为"不存在"（列目录没有、直接访问 404） |
| 生效范围 | 只作用于 `member`；超管不受限，访客只受「对访客隐藏」影响 |

权限标签页里的四个分组与「权限」页一一对应，唯一区别是：这里的开关**只能继续关闭**全局已开的项。
「**文件操作总开关**」关闭时，同组的 7 个写类子开关会一起**变灰**（因为它们实际已经不生效了）。

### 组长权限 `leaderCaps`

「基本」标签页里的四个开关决定组长在本组内能做什么，默认值如下：

| 能力 | 后台显示 | 默认 |
|:--|:--|:--|
| `viewMembers` | 查看本组成员名单 | 开 |
| `manageTodo` | 创建 / 编辑本组待办 | 开 |
| `editMemberAvatar` | 修改本组成员头像 | 关 |
| `manageMembers` | 管理本组成员与可见范围 | 关 |

成员只能切到自己所属的小组；超管可以切到任意小组。上限：小组最多 **200** 个，
每组最多 **500** 名成员、**100** 名组长。

## 权限

这一页分成六块。**改数值后别忘了点该块的「保存」**。

每一块的条目与默认值如下；权限点之间的依赖关系见 [权限与角色](/docs/zeroshadow/guide/permissions)。

### 1. 上传大小限制（单文件 MB）

| 输入框 | 配置字段 | 默认 |
|:--|:--|:--|
| 超级管理员 | `superUploadLimitMB` | 2048 |
| 团队成员 | `memberUploadLimitMB` | 512 |

### 2. ZIP 打包 / 解压限制

| 输入框 | 配置字段 | 默认 | 作用范围 |
|:--|:--|:--|:--|
| 最大文件数 | `zipMaxFiles` | 100 | 打包下载与在线压缩的条目数；解压时限压缩包内条目数 |
| 单文件最大 | `zipMaxSingleMB` | 50 | 打包时被选中文件的上限；解压时单个条目的上限 |
| 总大小最大 | `zipMaxTotalMB` | 128 | 打包的总量上限 |
| 解压 ZIP 最大 | `extractMaxZipMB` | 128 | 被解压的 `.zip` 文件本身体积上限 |

<Callout type="info" title="「解压后总量最大」在别处">
「解压后总量最大」不在这里，在**安全**标签页。
</Callout>

### 3. 链接下载工具限制（单个文件 MB）

| 输入框 | 配置字段 | 默认 |
|:--|:--|:--|
| 单个文件最大 | `downloadUrlMaxMB` | 4096 |

### 4. 团队成员权限

按分组排列，全部是即时保存的开关：

- **文件操作**（总开关 `fileWrite`）
  - 子项：上传文件、上传文件夹、新建文件夹、复制、移动、重命名、删除
  - 总开关关闭时子项整体变灰且失效（原因见 [权限与角色](/docs/zeroshadow/guide/permissions) 的「权限之间的依赖关系」一节）
- **下载与预览**：浏览目录、下载文件、下载文件夹、允许预览
- **高级功能**：压缩为 Zip、解压 Zip、多线程下载器、HTML 全屏预览、在线编辑文件
- **管理与账户**：管理访客可见性、修改密码

### 5. 访客权限

浏览目录、下载文件、下载文件夹、允许预览、压缩为 Zip、解压 Zip、HTML 全屏预览、在线编辑文件。

### 6. 对访客隐藏的文件夹

列出当前所有被隐藏的路径（显示成 `/路径`），点「恢复可见」即可取消。
列表为空时提示"在文件列表中右键文件夹可设为隐藏"。

## 数据与保留

这一页管的是"元数据类的开关与保留策略"：开关即时保存，带输入框的数值要点「保存」。

### 头像

| 项目 | 配置字段 | 默认 | 说明 |
|:--|:--|:--|:--|
| 允许成员设置头像 | `avatarEnabled` | **开** | 关闭后成员与超管都无法上传 / 修改头像（已上传的仍会显示） |
| 单张体积上限 | `avatarMaxKB` | **200** KB | 范围 1–10240；服务端只接受 128×128 的 WebP |

头像统一是 **128×128 的 WebP**：浏览器端先把选中的图片居中裁切缩放再上传，服务端同样校验格式与尺寸
（不是 128×128 直接拒绝），并按 `avatarMaxKB` 限制体积。接口只回传 `md5`，前端用 IndexedDB 缓存，
**没换过头像就不会重复下载**。头像会出现在顶栏右上角、成员表格、「小组」编辑器的成员列表与「团队待办」里。

### 团队待办

| 项目 | 配置字段 | 默认 | 说明 |
|:--|:--|:--|:--|
| 启用团队待办 | `todoEnabled` | **开** | 关闭后所有成员都看不到待办功能（侧边栏入口与接口一起失效）；`/team` 页面会显示明确的空状态「团队待办已被关闭」（旧版本在这里会因为拿不到列表而直接报错） |

### 默认上下文可见范围

不属于任何小组、或顶栏选择「默认」时生效的白 / 黑名单，对应
`defaultVisibility`（`{ whitelist, blacklist }`）。

- 两个文本框都是**每行一个相对路径**（例如 `项目A`、`公共资料/2026`）；白名单留空表示不限制，黑名单优先；
- 保存时会清洗：去掉首尾 `/`、把 `\` 统一成 `/`、丢掉 `.` 与 `..`、去重，每份列表最多 **200** 条；
- 单项判定是"等于该路径，或位于该路径之内"（Windows / macOS 上不区分大小写）。

### 日志与指标保留

| 项目 | 配置字段 | 默认 | 范围 | 说明 |
|:--|:--|:--|:--|:--|
| 采集请求指标 | `requestMetricsEnabled` | **开** | 开关 | 关闭后不再统计 QPS、状态码分布与慢请求 |
| 日志保留 | `logRetentionDays` | **30** 天 | 1–3650 | 超过天数的 `data/logs/zs-*.log` 会被清理 |
| 指标落盘保留 | `metricsRetentionDays` | **7** 天 | 1–365 | `data/metrics/zs-*.jsonl` 的保留天数 |
| 内存曲线窗口 | `metricsMemMinutes` | **15** 分钟 | 1–1440 | 内存里保留多少个每分钟采样点（同时决定 QPS 的统计窗口） |
| 慢请求阈值 | `slowRequestMs` | **1000** 毫秒 | 1–600000 | 超过该耗时的请求计入「慢请求」 |

### 数据备份与回滚

- 点「**立即备份**」对四个受管文件各做一次快照，提示「已创建 N 个文件的快照」；
- 覆盖写入前会**自动快照**旧内容，另外每天首次启动 / 访问时再做一次全量快照；
- 受管文件是 `config.json`（系统配置）、`users.json`（成员账户）、`groups.json`（小组）、`todos.json`（团队待办）；
- 「每个文件保留」对应 `backupKeep`（默认 **20**，范围 1–500），超出份数的旧快照按时间淘汰；
- 快照存放在 `data/backups/<文件名>/<时间戳>.json`；列表里点「回滚」即可用某份快照覆盖当前文件，
  回滚前会先把当前状态也快照一份（确认框里写着"当前状态也会先自动快照一份以便反悔"）；
- 备份总开关是 `backupEnabled`（默认 **开**）：关掉后连写入前的自动快照也不再产生。
  这一页没有对应的开关，需要手工编辑 `data/config.json`，或在 `PATCH /api/admin/config` 里传该字段
  （字段说明见 [配置参考](/docs/zeroshadow/admin/configuration)）。

## 安全

### 接口限流

| 项目 | 说明 |
|:--|:--|
| 开启限流 | 总开关（`rateLimitEnabled`），默认**开** |
| 每分钟上限 | 单 IP 每分钟允许的"重型操作"次数（`rateLimitPerMin`），默认 **120** |

**受限的接口**：打包下载、在线压缩、在线解压、递归搜索、查看详情、链接下载。
**不受限的接口**：普通列目录、单文件下载——因为画廊预览、连续下载这类正常使用会产生大量请求。

超限时返回 429「操作过于频繁，请 N 秒后再试」，并带上 `Retry-After` 头。

### 解压保护

| 项目 | 说明 |
|:--|:--|
| 解压总量最大 | `extractMaxTotalMB`，默认 **512 MB** |

超出时会**中止解压并清理已写出的内容**，避免用一个小压缩包把磁盘占满。
（先按压缩包头声明的大小快速拒绝，解压过程中再按实际写出的字节累计复核。）

### 其他安全开关

| 开关 | 配置字段 | 默认 | 关闭后会怎样 |
|:--|:--|:--|:--|
| 允许复制只读映射目录的内容 | `softDirAllowCopyOut` | **关** | 关闭时，只读映射目录里的内容**不能**复制 / 压缩进网盘目录 |
| 作业进度仅创建者可见 | `jobStatusOwnerOnly` | **开** | 关闭后，团队成员之间可以互相看到压缩 / 解压 / 链接下载任务的文件名与进度 |
| 链接下载允许访问内网地址 | `downloadUrlAllowPrivate` | **关** | 关闭时禁止链接下载工具抓取内网 / 回环 / 链路本地 / 云元数据地址；等效于 `.env` 的 `DOWNLOAD_URL_ALLOW_PRIVATE` |
| 写操作校验请求来源 | `csrfOriginCheck` | **开** | 关闭后不再校验 `Origin` / `Sec-Fetch-Site`（仍保留自定义请求头校验）。**反向代理改写了 Host 头导致写操作被误拦时**才需要关 |

<Callout type="warn" title="「允许复制只读映射目录的内容」为什么默认关闭">
「允许复制只读映射目录的内容」默认关闭是有原因的：如果你把项目根目录之类的位置映射进来，
低权限成员本来可以顺手把 `.env`、`data/.jwt-secret` 复制到一个公开目录再下载走。
</Callout>

### 客户端 IP 解析

这一块只**显示**当前状态（徽章上写着"直连（不信任代理头）"或"信任代理头 xxx"），**不能在这里改**。
它由服务端 `.env` 的 `TRUST_PROXY` 决定，改动后需要**重启服务**。

- 只通过隧道 / 反向代理访问时设为 `loopback`，日志与按 IP 限速才会用真实客户端 IP；
- 如果服务**同时能被直接访问**，请保持关闭，否则客户端可以伪造该请求头绕过限速。

详细取值与取舍见 [公网访问与隧道](/docs/zeroshadow/admin/tunnel#4-trust_proxy-该怎么填)。

## 公网

### SSH 反向隧道

| 控件 | 说明 |
|:--|:--|
| 启用公网访问 | 总开关。打开后立刻尝试建立隧道 |
| 隧道服务 | `pinggy.io（推荐）` / `localhost.run` / `serveo.net` / `自定义 SSH` |
| SSH 目标 | **仅在选择「自定义 SSH」时出现**，格式 `user@host` 或 `user@host:端口`；需要本机已配置免密 SSH 密钥 |
| 应用并重连 | 仅隧道已启用时出现，用于按当前配置重连 |

**切换「隧道服务」时，如果隧道正在运行，会立刻按新模式重连。**

### 运行状态

- 徽章：`运行中` / `未运行`
- 公网地址：抓到后显示在只读输入框里，点一下可全选复制
- 重连次数：自动重连过多少次（没重连过时显示"隧道日志"）
- 输出区：隧道进程最近 40 行输出（含实际执行的 `ssh` 命令）

隧道断开后会自动重连，退避从 5 秒开始逐次翻倍，最长 60 秒一轮。

<Callout type="error" title="未检测到 SSH 客户端">
隧道需要服务端能执行 `ssh` 命令。如果没有安装 SSH 客户端，输出区会提示
`错误: 未检测到 SSH 客户端，请先安装 OpenSSH Client`，并给出 Windows 的安装路径提示。
</Callout>

完整的隧道模式对照、`ssh` 参数与排查方法见 [公网访问与隧道](/docs/zeroshadow/admin/tunnel)。
