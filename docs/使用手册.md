# 使用手册

面向**日常使用者**（超管、团队成员、访客都适用）。这一篇讲的是"界面上每个按钮干什么、点了会发生什么"。
权限点是否对你开放，取决于你的角色与超管的设置，详见 [权限与角色](权限与角色.md)。

---

## 1. 界面结构

```
┌──────────┬──────────────────────────────────────────────────────────┐
│ ZeroShadow│ 顶栏：手机端菜单 / 搜索框 · 小组切换 · 主题 · 登录状态    │
│ v1.1.0    ├──────────────────────────────────────────────────────────┤
│ 文件      │                                                          │
│ 团队 *    │   主内容区：文件浏览器 / 团队待办 / 设置 / 工具 / 开源信息│
│ 工具      │                                                          │
│ 设置      │                                                          │
│ 开源信息  │                                                          │
│ ──────    │                                                          │
│ « 折叠    │                                                          │
└──────────┴──────────────────────────────────────────────────────────┘
        * 「团队」只在已登录时出现
```

- **侧边栏**（窄屏时收进左上角的菜单按钮）常见为四项：文件、工具、设置、开源信息；
  **登录后**会多出一项**「团队」**（团队待办，见 [§14](#14-团队待办)）。
  最上方是品牌区：第一行 `ZeroShadow`，第二行 `v<版本号>`（版本号取自 `web/src/version.ts`，
  与「软件开源信息」页显示的是同一个值）；折叠后品牌区只剩一个图标。
- **侧边栏可以折叠**：导航列表**下方**有一个「折叠 / 展开」按钮（图标是 `panel-left-close` /
  `panel-left-open`），也可以在侧边栏空白处右键选「收起侧边栏」；点一下会动画收成"只剩图标"的窄条
  （图标上悬停有文字提示），再点一下恢复。折叠状态记在浏览器本地
  （`zs-client-settings` 里的 `sidebarCollapsed`，旧的 `zs-sidebar-collapsed` 键会在读取时自动迁移），
  刷新和下次打开都保持；**窄屏的手机抽屉不受影响**，始终显示完整文字。
- **设置** 里的管理类标签页（状态 / 日志与指标 / 成员 / 小组 / 权限 / 数据与保留 / 安全 / 公网）
  **只对超级管理员显示**。
- **顶栏**右侧：**小组切换器**（已登录时出现，用于切换当前小组上下文，见 [§15](#15-小组上下文)）、
  主题切换按钮；未登录时显示「登录」按钮，已登录时显示头像 + 用户名，点开头像卡片可以换头像、
  改密码（成员）或退出登录。
- **顶栏搜索框只在窄屏（<640px）出现**；宽屏时搜索框在文件浏览器的工具栏里。两者行为一致。
- 文件浏览器**底部**有一行提示，写着当前身份，例如 `当前为"访客"模式`、`当前为"团队成员"模式，其他功能需要管理员模式`。

网页路由一览（可以直接在地址栏访问）：

| 路径 | 页面 |
|:---------------------- |:------------------------ |
| `/` | 文件浏览器 |
| `/login` | 登录 |
| `/team` | 团队待办（访客会被引导去登录） |
| `/settings` | 设置 |
| `/preview?path=…` | 文件预览（全屏） |
| `/editor?path=…` | 在线文本编辑器（全屏） |
| `/html-preview?path=…` | HTML 全屏预览（全屏） |
| `/tools` | 工具 |
| `/about` | 软件开源信息 |

访问不存在的路径会自动跳回 `/`。

## 3. 上传

三种方式：

1. 点工具栏「上传」，选择一个或多个文件；
2. 点「上传文件夹」，选择整个文件夹（浏览器会带上相对路径）；
3. **直接拖拽**文件或文件夹到列表区域，出现"松开以上传到当前文件夹"提示时松手。

上传过程中右下角会出现**上传进度面板**：

- 显示文件名（多文件时显示"某某 等 N 个文件"）、进度条、已传输 / 总大小；
- 上传中可点右侧 `×` 取消；
- 完成后点面板标题右侧 `×` 清除已完成记录；
- 结果提示：全部成功显示「已上传 N 个文件」，有失败项会列出具体原因。

### 上限与规则

| 规则 | 值 | 来源 |
|:------------------ |:--------------- |:------------------------ |
| 单文件大小（成员） | 默认 512 MB，超管可改 | 「设置 → 权限 → 上传大小限制」(`memberUploadLimitMB`) |
| 单文件大小（超管） | 默认 2048 MB，超管可改 | 「设置 → 权限 → 上传大小限制」(`superUploadLimitMB`) |
| 单次请求文件数 | 100（**客户端会自动分批**） | 服务端上传解析限制 |
| 文件名 | 自动清洗掉 `\ / : * ? " < > \|` 与控制字符，去尾部空格与点 | 服务端 |
| 重名 | 默认自动改成 `名字 (1).ext`；也可以在上传时选择覆盖 / 跳过后再传 | — |
| 上传文件夹时的重名 | 以**顶层文件夹名**为单位询问，可对每个顶层文件夹分别选择合并 / 覆盖 / 重命名 / 跳过 | — |

**一次选超过 100 个文件也没关系**：网页会把它们自动切成每批 100 个依次上传，进度条与「已上传 N 个文件」是
整批的合计结果。如果你绕过网页直接调接口，单次请求里第 101 个及以后的文件会被服务端忽略，
响应的 `truncated` 为 `true` 作为提示。

**文件夹上传会真实保留目录结构**：浏览器带上的相对路径（`子目录/文件.txt`）会被服务端照原样建目录，
子树层级不会丢。上传过程中若中断，**不会留下空目录树**，临时文件也会被清理。

超出大小限制的文件会被拒绝，并逐条给出「超出大小限制 (NMB)」提示，**不会**产生半个残缺文件。
上传的文件先落到 `data/tmp/`，落盘成功后才移动到目标目录，因此不会出现"下载到一半的文件"。
若服务器磁盘写满，只有这一个文件会失败（提示「服务器磁盘空间不足」），**服务不会因此退出**。

## 4. 下载

| 你选了什么 | 会发生什么 |
|:--------------------- |:--------------------------------------- |
| 单个文件 | 直接下载该文件，中文文件名会正确保留 |
| 单个文件夹 | 打包成 `<文件夹名>.zip` 下载 |
| 多选（文件 / 文件夹混选） | 打包成 `ZeroShadow-<日期>.zip` 下载 |

打包规则：

- 打包时**排除符号链接**；访客打包时会**自动跳过对其隐藏的文件夹及其内容**（递归跳过整棵子树）；
- 登录成员打包时同样会**递归跳过当前小组 / 默认可见范围之外的目录**，不会出现"列表里看不到、zip 里却有"；
- 空文件夹会在压缩包里保留一个 `.keep` 占位文件；
- 多个不同目录下**同名**的条目会自动用路径（`/` 换成 `_`）区分，仍然重名则追加 `_2`、`_3`…

打包上限（「设置 → 权限 → ZIP 打包 / 解压限制」）：

| 限制 | 默认值 | 说明 |
|:-------------- |:-------- |:--------------------------------------- |
| 最大文件数 | 100 | 超出直接拒绝，提示实际数量 |
| 单文件最大 | 50 MB | 校验的是**被选中的那些文件**本身；所选文件夹内部的文件不单独校验，而是计入总量上限 |
| 总大小最大 | 128 MB | 递归统计的总量上限（文件夹内部的文件都算） |

> 打包需要遍历目录统计体积，因此这个接口**受接口限流保护**（默认单 IP 每分钟 120 次）。
> 若提示「操作过于频繁，请 N 秒后再试」，等一会儿或让超管放宽限流即可。

## 5. 文件预览

双击可预览的文件（或右键 →「预览」）会进入全屏预览页，按 `Esc` 退出。

| 类型 | 支持格式 | 交互 |
|:-------- |:----------------------------------------------------- |:--------------------------------------- |
| **图片** | jpg / jpeg / png / gif / webp / bmp / avif / tiff / tif / heic / ico / svg | 默认等比适配窗口；滚轮缩放（0.1×–10×）；按住左键拖拽平移；双击放大 / 还原；右上角有放大、缩小、重置按钮与当前缩放百分比 |
| **视频** | mp4 / webm / mov / mkv / wmv / flv / 3gp / m4v | 自动播放，使用浏览器原生控制条（能不能播取决于浏览器是否支持该编码） |
| **音频** | mp3 / wav / ogg / flac / m4a / aac | 自动播放，显示文件名 |
| **PDF** | pdf | 内嵌浏览器 PDF 阅读器 |
| **文本** | txt / md / json / log / csv / js / ts / css / py / yml / yaml / xml / ini / conf / rst / adoc / tex / bat / ps1 / vbs / lua / rb / php / pl / sql / toml / properties / graphql / rtf / org / cmake / gradle / dockerfile / makefile / .gitignore / .env | 以等宽字体**原样**显示（不做 Markdown 渲染，也不做语法高亮）；文本里的引号、尖括号等字符**按原样显示**，不会被转义成 `&quot;` / `&lt;` 之类的实体 |

不在上面的格式（docx / zip / exe …）**不会被当成文本硬拆**：直接打开预览页时会显示
「**暂不支持预览此格式**」，在文件列表里双击则按权限直接下载。

预览页面本身是只读的，不会修改服务器上的文件。

> **文本预览不识别编码**：预览页是把文件按浏览器默认方式（UTF-8）直接显示的，
> 所以 GBK / Big5 的文件在预览里可能是乱码。要看正确内容请用**在线编辑**打开
> （它会自动识别编码，见 [§6](#6-在线编辑)）。

### HTML 全屏预览

**双击 `.html` / `.htm` 文件**：有「HTML 全屏预览」权限时直接进入 HTML 预览页；
没有权限时退化为普通**文本预览**（看到的是源码）。右键菜单里也有对应的「HTML 预览」项。

HTML 预览在**沙箱 iframe** 中渲染（`sandbox="allow-scripts"`，不含 `allow-same-origin`）。
这意味着页面里的脚本可以运行，但**拿不到网盘的 Cookie 与接口会话**——这是刻意的安全设计，
详见 [安全设计](安全设计.md#5-html-与-svg-的沙箱处理)。

## 6. 在线编辑

右键可编辑文件 →「在线编辑」，进入全屏编辑器（路由 `/editor?path=…`）：

- 编辑器是纯文本编辑（等宽字体，不做语法高亮、不做自动补全）；
- `Ctrl`/`⌘ + S` 或点右上角「保存」写回服务器；
- 文件名后面出现「未保存」徽章表示有改动；有改动时关闭 / 按 `Esc` 会弹确认框（「继续编辑」/「放弃并离开」）；
- 保存是**原子替换**（先写临时文件再改名），保存途中断电也不会把原文件截断成半个；

### 编码

**旧版只有 UTF-8**：打开 GBK 的 txt 是满屏乱码，保存还会把文件写坏。现在编解码交给服务端：

- 打开文件时自动识别编码，工具栏左上角的下拉框显示识别结果，可手动切换；
- 支持的编码：`UTF-8`、`UTF-8 (带 BOM)`、`UTF-16 LE`、`UTF-16 BE`、`GB18030 / GBK（简体中文）`、
  `Big5（繁体中文）`、`Shift_JIS（日文）`、`EUC-KR（韩文）`、`Windows-1252（西欧）`、`ISO-8859-1（Latin-1）`；
- 识别顺序是 **BOM → 无 BOM 的 UTF-16 → 严格 UTF-8 → 按常用字频率逐个候选编码打分**：
  所以 Big5 不会被误认成 GB18030、Shift_JIS 也不会被误认成 UTF-16；
- 识别只是**猜测**时（分差不够大），页面会提示「编码识别为 xxx，如果显示乱码请在工具栏手动切换编码」；
- **切换编码会重新读取文件**（改编码需要原始字节），有未保存改动时会先弹确认框；
- 保存时按当前编码写回，`UTF-8 (带 BOM)` / `UTF-16 LE` / `UTF-16 BE` **会自动写入 BOM**；
- **目标编码表示不了的字符会被拒绝保存**（提示「这些字符无法用 xxx 表示：… 请改用 UTF-8 保存」），
  而不是悄悄写成 `?` 把内容改坏——例如把含简体字的文本存成 Big5。

### 换行符

工具栏的换行符下拉框有 `CRLF` / `LF` / `CR` 三档：

- 打开时按原文件的风格自动选中（优先识别到 `CRLF` 就选 CRLF）；
- 正文里统一按 `LF` 显示与编辑，**保存时才按这个选择还原**；
- 保存在状态栏会回报实际写入的编码与换行风格。

### 编辑功能

| 功能 | 说明 |
|:-------------- |:----------------------------------------------------------- |
| 行号 | 左侧行号栏，随正文滚动；**开启自动换行时自动隐藏**（换行后行号会与视觉行错位） |
| 自动换行 | 工具栏按钮切换；关闭时不折行、横向滚动 |
| 字号 | 工具栏 `-` / `+` 在 11–22 之间调整，当前值显示在中间 |
| 查找 | `Ctrl`/`⌘ + F`（或 `Ctrl+G`）打开查找条；`Enter` / `F3` 下一个，`Shift+F3` 上一个；显示 `当前/总数` |
| 替换 | `Ctrl`/`⌘ + H` 打开替换条，多出「替换」「全部替换」与替换内容输入框 |
| 区分大小写 / 正则 | 查找条上的两个开关按钮；正则无效时替换会提示「正则表达式无效」 |
| 跳转到行 | 查找条右侧的行号输入框，回车跳过去 |
| Tab 缩进 | 在编辑器里按 `Tab` 插入**两个空格**（不跳走焦点） |
| 状态栏 | 行 / 列、选中字符数、总行数、字符数、编码、换行符、文件大小；超过 **2 MB** 会提示「文件较大，编辑可能有卡顿」 |

支持的扩展名：`txt md mdx py cpp log html htm js ts css json xml yml yaml ini conf sh java c rs go rst adoc tex bat ps1 vbs lua rb php pl sql toml properties graphql rtf org cmake gradle gitignore env dockerfile makefile`。

### 上限与只读

- 单次**读取**上限 **8 MB**，超过提示「文件过大（NMB），在线编辑上限 8MB」；
- 单次**保存**的内容上限是 **16 MB**，超过会提示「内容过大（NMB），在线编辑上限 16MB」；
- **二进制文件不能当文本打开**：含 NUL 字节或控制字符过多的文件会提示
  「这看起来是二进制文件，不能当文本编辑」（UTF-16 文件不受 NUL 检查影响）；
- 只读映射目录里的文件**不能**在线编辑：菜单项变灰，编辑器里也会显示「只读目录」徽章且无法保存。

## 7. 搜索

在搜索框输入关键词后按 `Enter`：

- 网页界面的搜索**始终从网盘根目录开始递归**（不受你当前所在目录影响），匹配规则是**文件名包含关键词**（不区分大小写）；
- 结果列表显示文件名、类型、大小，以及它所在的路径（点击路径可以跳过去）；
- 搜索结果最多返回 200 条，单次搜索最长约 6 秒、最多访问 30000 个条目，超出就返回已找到的部分；
- 搜索框里输入的关键词限制在 100 个字符以内；
- 点结果上方的「清除」或清空关键词回车，即可回到正常浏览。

搜索接口属于重型操作，**受接口限流保护**。

## 8. 压缩与解压

### 压缩为 Zip

- 右键单个文件夹 →「压缩为 Zip」；多选后 →「压缩所选为 Zip」；
- 压缩结果**放在被压缩对象所在的目录**，名字为 `<名字>.zip` 或多选时的 `ZeroShadow-<日期>.zip`；重名会自动加 `(1)`；
- 右下角「处理」面板显示实时进度（按文件条目数计算）与百分比，完成后弹出「压缩完成」；
- 上限与打包下载相同（文件数 / 单文件 / 总量）。

### 解压 Zip

- 右键 `.zip` 文件 →「解压到当前目录」；
- 解压出来的内容会放进**以压缩包名命名的新文件夹**（去掉 `.zip` 后缀），重名自动加 `(1)`；
- 只支持 `.zip`，其他压缩格式（rar / 7z 等）会提示「只能解压 zip 文件」；
- 三重保护：
  1. 压缩包文件本身大小超过「解压 ZIP 最大」（默认 128 MB）直接拒绝；
  2. 压缩包头里声明的解压后总大小超过「解压总量最大」（默认 512 MB）直接拒绝；
  3. 解压过程中**按实际写出的字节**累计，一旦超过上限立即中止，并**删除已经写出的半成品目录**；
- 压缩包内的条目数超过「最大文件数」（默认 100）也会被拒绝；
- 压缩包内形如 `../../x` 的越界条目会被**静默跳过**，不会写到目标目录之外（zip-slip 防护）。

进度面板：正在解压时显示百分比，完成后提示「已解压 N 个文件」。

## 9. 复制、移动、粘贴、重命名、删除

### 复制 / 剪切 → 粘贴

1. 选中若干项 → 右键「复制」或「剪切」（也可用 `Ctrl/⌘ + C` / `Ctrl/⌘ + X`）；
2. 进入目标目录 → 点工具栏出现的「粘贴 N 项」按钮（或按 `Ctrl/⌘ + V`）。

复制模式下原文件保留，剪切模式下原位置的文件被移走。剪贴板是**浏览器内存里的状态**，刷新页面就清空。

> 如果把项目"剪切"后粘贴回它**原本所在的目录**，服务端会跳过多余的移动动作（视为已完成），不会报错也不会产生副本。

### 复制到… / 移动到…

右键 →「复制到…」/「移动到…」会打开一个目录选择器，可以直接选目标目录并确认，不用先跳过去。
选择器里**不能选中源目录自身或其子目录**（按钮会变灰）。

### 重命名

右键 →「重命名」（或按 `F2`）。新名字会校验：不能为空、不超过 200 字符、不能含 `\ / : * ? " < > |`、不能以空格或点结尾。
目标是当前目录，所以**不会移动文件**。

### 删除

右键 →「删除」（或按 `Delete`）。会弹出确认框，显示将永久删除哪些项，**不可撤销**。
根目录本身不能被删除。

### 同名冲突处理

只要操作会导致"目标位置已存在同名项"，就会弹出「同名文件处理」对话框，逐个列出冲突项。
每一项下面是一排**分段按钮**（直接点选，不用下拉），可选：

| 选项 | 效果 |
|:-------- |:--------------------------------------- |
| **重命名为 xxx (1)** | 按按钮上显示的新名字写入（服务端会重新校验这个名字合不合法、是否仍然冲突） |
| **跳过** | 这一项不处理 |
| **覆盖** | 删除目标位置已有的同名项，再写入 |
| **合并** | **仅当双方都是文件夹时可选**，把源目录的内容逐个合并进目标目录（同名子项按同样的规则处理，同名文件以源为准） |

- **默认选择**：文件夹冲突默认「合并」，文件冲突默认「重命名」；
- 冲突项多于一个时，会出现「对接下来所有同名项目执行此操作」复选框，勾上后**从当前项开始往后**全部套用同一选择
  （选「重命名」时，每一项仍会各自生成不冲突的名字）；
- **取消是真的取消**：点「取消」、按 `Esc`、或点对话框外的灰色遮罩，整个操作都会中止，
  **一个文件都不会动**——剪切模式下也不会出现"点了取消但文件已经被移走"的情况；
- 上传时对**顶层文件夹**的冲突同样走这个对话框，「覆盖」与「合并」在这里都表示
  "同名文件用新版本替换，其余原样写入"，选「重命名」则整个顶层文件夹换个名字写入。

## 10. 访客可见性

对**文件夹**右键 →「对访客隐藏」，该项及其整个子树的名称会从访客的列表与搜索结果中消失，
访客直接访问该路径会得到「目录不存在」，访客打包下载时也会被跳过。

- 只有文件夹可以设置（对文件设置会提示「只能对文件夹设置访客可见性」）；
- 根目录不能设置；
- 非访客成员仍然能看到，且列表里会有个"眼睛斜杠"小图标标识；
- 重命名 / 移动被隐藏的文件夹时，隐藏记录会**跟着一起更新**；删除该文件夹时对应记录一并清理；
- 已隐藏的列表可以在「设置 → 权限 → 对访客隐藏的文件夹」里查看，并点「恢复可见」取消。

## 11. 快捷方式（`.zeropath`）

快捷方式本质上是一个内容为 JSON 的 `.zeropath` 文件，用来把常用入口固定到某个目录里，或者给某项起一个更友好的名字 / 换一个图标。

创建方式：

- 右键任意文件 / 文件夹 →「创建快捷方式」（自动填好目标）；
- 或在空白处右键 →「创建快捷方式」（手动填写目标）。

对话框中可填：

| 字段 | 说明 |
|:-------------- |:--------------------------------------- |
| 显示名称 | 在列表里显示的名字 |
| 目标路径 | 相对网盘的路径，或只读映射目录下的路径 |
| 目标类型 | 目录 / 文件 / 外部映射目录 / 外部映射文件 |
| 图标 | 从 18 个内置图标里挑一个（folder、file、image、film、music、globe、link…） |

保存后生成 `显示名.zeropath`。双击快捷方式：

- 目标是目录 → 跳进该目录；
- 目标是文件 → 有预览权限就打开预览，否则直接下载；
- 目标不存在或数据损坏 → 提示「快捷方式目标不存在或无权访问」/「快捷方式数据损坏」。

> 创建与修改快捷方式都要经过「保存文件」接口，因此需要「在线编辑文件」权限。

## 12. 工具页

侧边栏进入「工具」，目前有两个标签页。

### 大小转换

输入数值并选择单位（B / KB / MB / GB / TB），一次性列出其余单位的换算结果。
换算按 **1024 进制**（1 KB = 1024 B）。

### 链接下载器

界面上的名字是「多线程下载器」，实际行为是：**服务端拿着你给的直链去抓取文件，落到网盘指定目录**。

用法：

1. 填「下载链接」，只支持 `http://` 与 `https://`；
2. 填「保存到」（留空 = 根目录），可以点「浏览」用目录选择器挑；
3. 需要改文件名时填「文件名」（留空则按链接最后一段自动识别，非法字符自动清洗，重名自动加编号）；
4. 点「开始下载」，下方「下载任务列表」显示进度、完成状态；失败会显示具体原因。

限制与规则：

| 项 | 说明 |
|:------------------ |:--------------------------------------- |
| 单个文件大小上限 | 默认 4096 MB（「设置 → 权限 → 链接下载工具限制」`downloadUrlMaxMB`） |
| 重定向次数 | 最多 5 跳，且**每一跳都重新校验目标地址** |
| 连接超时 | 60 秒 |
| 内网地址 | **默认禁止**访问内网 / 回环 / 链路本地 / 云元数据地址；确有需要时由超管在「设置 → 安全 → 链接下载允许访问内网地址」或 `.env` 中显式放开 |
| TLS 证书 | 默认严格校验；只有设置 `DOWNLOAD_URL_INSECURE_TLS=1` 才跳过（不推荐） |
| 下载中断 | 若实际收到的字节数明显少于 `Content-Length`，会判定为"下载未完成"并报错，不会留下残缺文件 |

访客**没有**这个功能；成员需要超管在「设置 → 权限 → 高级功能 → 多线程下载器」里开启。

## 13. 任务面板

右下角会出现两类浮动面板，两者同时存在时，操作面板会自动上移避免重叠。

| 面板 | 内容 | 可做的操作 |
|:--------------- |:--------------------------------------- |:------------------------ |

任务进度只对**创建者与超管**可见（可在「设置 → 安全」里放开，让成员之间互相可见）。

## 14. 团队待办

侧边栏的**「团队」**页（也可以直接访问 `/team`）是给超管、组长与被指派成员用的轻量任务清单。
**访客看不到它**：未登录时页面会提示「登录后可查看团队待办」并给一个「去登录」按钮。

页面是**整页单列滚动**（不再有"列表自己滚、外面也滚"的双层滚动区），从上到下依次是：
标题与「新建待办」、筛选工具条、待办列表、组长专属的「我管理的小组」。

> 超管在「设置 → 数据与保留 → 团队待办」里关掉开关后，页面会显示明确的空状态
> 「**团队待办已被关闭**」，并说明"管理员在「设置 → 权限」里关闭了团队待办功能；重新开启后这里就能继续使用"，
> 而不是抛出一个坏掉的空页面。

### 列表与筛选

- 顶部标题：「团队待办」，右上角是「新建待办」——**只有超管与组长看得到**这个按钮；
- **筛选工具条**：状态分段、范围分段与搜索框收进**同一块带边框的工具条**里（不再各占一行）：
  - **状态**分段按钮：`进行中`（默认） / `已完成` / `全部`；
  - **范围**分段按钮：`全部范围` / `小组` / `成员`；
  - 带放大镜图标的**搜索框**：在标题与备注里做包含匹配（输入即筛选）；
- **待办列表是页面的主体卡片**，放在最显眼的位置；列表上方的计数条显示 `共 N 条 · 未完成 M 条`；
  没有任何待办时显示空状态（能创建的人看到「点击右上角「新建待办」下发第一条任务」，
  其他人看到「当前筛选条件下没有待办」）。

### 单条待办

- 左侧复选框：勾选 / 取消勾选即「完成 / 未完成」，改动会记下完成人；
- 标题右侧的**优先级徽章**：高（实心）/ 中 / 低（描边）；
- 标题下方是备注（最多显示两行）、范围标签（`全体` / `小组·组名` / `成员·用户名`）、
  截止日期（**已逾期**显示红色、**今天到期**显示琥珀色）、创建者头像与用户名，完成时还会显示「由 X 完成」；
- 右侧 `⋯` 菜单按权限显示「编辑」「标记完成 / 标记未完成」「删除」，行上**右键**还有一份同样的菜单
  再加「复制标题」「复制备注」。

### 新建 / 编辑待办

对话框里的字段是成组排列的：

| 字段 | 说明 |
|:-------------- |:--------------------------------------- |
| 标题 | 必填，不超过 200 字 |
| 备注 | 可留空，不超过 2000 字 |
| 优先级 | 分段按钮：`高` / `中`（默认） / `低` |
| 截止日期 | 日期选择器，可留空 |
| 下发范围 | 分段按钮：`全体成员`（仅超管可见）/ `指定小组` / `指定成员`；选后两者时下方会出现具体的小组 / 成员下拉。**只在新建时出现**，建好后界面不再提供改范围 |
| 允许被指派成员编辑内容 | 勾选框；勾上后范围内的人也能修改这条待办的内容（只有创建者与管理者能改这个勾选） |

**谁看得到哪条待办**：

- `全体` → 所有登录成员；
- `小组` → 该小组成员、该组组长、创建者与超管；
- `成员` → 被指派的成员本人、其所在小组中拥有「创建 / 编辑本组待办」能力的组长、创建者与超管。

### 我管理的小组（组长）

组长在**待办列表下方**能看到「**我管理的小组**」卡片（超管与普通成员看不到）：

- 它是**紧凑的一行一个小组**的列表：小组名、成员数徽章、可见范围徽章
  （`白名单 N` / `可见不限`，有黑名单时追加 `· 隐藏 N`），还能看到前 6 位成员的头像与用户名（超出显示「等 N 人」）；
- 每行右侧的「管理」按钮打开**小组管理对话框**，里面分两个标签：
  - **成员**：搜索成员，逐个加入 / 移出本组（移出会同时取消其组长身份）；没有「查看本组成员名单」能力时只显示
    「组长能力里未开启「查看本组成员名单」」；
  - **可见范围**：`可见白名单` 与 `隐藏黑名单` 两个多行输入框（每行一个目录，相对网盘根目录），
    各自的右上角有「**从目录选择**」按钮，打开**目录选择器**——像文件浏览器一样逐层点进目录，
    选中后会把该目录追加到对应的输入框里；白名单留空表示不限制，黑名单优先级高于白名单；
    改完点「保存可见范围」。
- 具体能做哪些取决于超管为该组勾选的组长能力，见 [权限与角色](权限与角色.md#3-小组权限收窄与可见范围)。

> 待办数量上限 **5000** 条；删除小组成员时，指派给他的待办会转为「全体」。

## 15. 小组上下文

**团队成员**（以及超管）会在顶栏看到一个**小组切换器**：默认显示「默认」，点开可以在自己所属的小组之间切换，
每一项前面有该组的颜色圆点。切换后会立刻发生三件事：

| 变化 | 说明 |
|:-------------- |:--------------------------------------- |
| **能看到的目录** | 只显示当前小组可见范围内的目录；范围外的目录对你就**像不存在**（列表里没有、直接访问返回 404、打包也会跳过） |
| **能做的操作** | 按当前小组的权限收窄生效，例如该组关掉了「上传文件」，上传按钮就会置灰 / 不可用 |
| **能看到的待办** | 「团队」页按新小组的范围重新筛选 |

- 切换小组后页面会回到文件浏览器根目录，避免停留在已经不可见的目录里；
- 你的选择记在浏览器本地（`zs-group-context`）；如果所选小组被删除、或你被移出该组，
  会自动回退到「默认」；
- **「默认」上下文**就是"不套用任何小组"：使用全局成员权限，可见范围由超管在
  「设置 → 数据与保留 → 默认上下文可见范围」里设定（默认不限制）；
- 访客看不到这个切换器；超管可以切换到任意小组，但**可见范围与权限收窄对超管不生效**。

## 16. 账户相关

### 登录 / 退出

- 右上角「登录」→ 用户名 + 密码；
- 账号被禁用时登录会提示「您的账户已被禁用」；
- 已登录后点右上角头像 →「退出登录」。

### 头像

- 点右上角头像打开账户卡片，**点头像本身**（卡片左侧的圆形头像，卡片上还有一行「头像自动裁剪为 128×128」）
  即可选择本地图片更换，鼠标悬停时头像上会浮出相机图标；
- 图片在浏览器里自动**居中裁切缩放成 128×128 的 WebP** 再上传，服务端同样只接受 128×128 的 WebP，
  并按「设置 → 数据与保留 → 头像 → 单张体积上限」（默认 200 KB）限制体积；
- 换完后顶栏、成员列表、小组对话框、待办里的头像会一起更新；头像只回传
  `md5`，浏览器用 IndexedDB 缓存，**没换过就不会重复下载**；
- 超管可以在「设置 → 成员」里给任意账户换头像：点表格里的头像，或在该成员 `⋮` 菜单里选
  「设置头像」/「恢复默认头像」；组长在所在小组开启「修改本组成员头像」时也能改本组成员的头像，
  但目前只有接口入口（见 [API 参考 · 头像](API参考.md#4-头像-apiavatars)），界面上的成员管理仍只对超管开放。

**没有上传头像的人会得到一个自动生成的默认头像**（渐变圆底 + 两个字符的缩写）：

- 渐变由**色相 24 档 × 副色相 4 档 × 明度 3 档 = 288 种组合**里选一种（用稳定哈希按显示名取，
  同一个人在任何位置颜色都一样）；
- 缩写规则：**中日韩名字取后两个字**（同姓太多，姓氏几乎没有区分度）、
  拉丁文名字有多个词时取前两个词的首字母（`Wang Yuqian` → `WY`）、
  单个词时取首字母 + 末字母（`wangyq` → `WQ`）；
- 旧版默认头像是"8 种纯色 + 一个首字母"，十几人的团队里很容易撞脸（`wangyq` 与 `wanglei` 都是 `W`），
  现在 288 种外观叠加两个字符后基本不会认错人。

### 修改密码

- **团队成员**：点头像 →「修改密码」，需要输入旧密码与新密码（至少 6 位）。没有「修改密码」权限时该入口显示为灰色。修改成功后会被强制退出登录，需要重新登录。
- **超级管理员**：密码**不能**在网页里改，点「修改密码（编辑 .env）」会提示：编辑 `.env` 中的 `SUPER_ADMIN_PASSWORD` 后**重启服务**。重启后所有旧登录会话立即失效。

### 主题与外观

- 右上角主题按钮在 **浅色 → 深色 → 跟随系统** 之间循环；
- 「设置 → 外观」里有显式的三选一分段控件（浅色 / 深色 / 跟随系统）；
- 键盘上按 `D` 键也能切换浅色 / 深色（在输入框里打字时不会触发）。

「设置 → 外观」还提供这些**只作用于本机浏览器**的偏好（保存在 `localStorage` 的
`zs-client-settings`，详见 [配置参考 · 浏览器本地存储](配置参考.md#四浏览器本地存储localstorage)）：

| 分组 | 项目 | 可选值 |
|:-------- |:-------------- |:--------------------------------------- |
| 主题 | 主题 | 浅色 / 深色 / 跟随系统 |
| 界面 | 界面密度 | 舒适 / 紧凑（紧凑会收紧列表行高与卡片内边距） |
| 界面 | 字号 | 小 / 标准 / 大（整体缩放界面文字） |
| 界面 | 默认折叠侧边栏 | 开关（仅桌面端） |
| 界面 | 背景噪点 | 开关（页面底层的细微噪点纹理） |
| 界面 | 减少动画 | 开关（关闭列表与页面的 GSAP 入场动画、以及界面过渡效果） |
| 文件浏览默认值 | 视图 | 列表 / 网格 |
| 文件浏览默认值 | 排序字段 / 排序方向 / 文件夹置顶 | 名称、大小、修改时间 / 升序、降序 / 开关 |

卡片右上角有「恢复默认」，一键把这些偏好还原。

## 18. 换台设备还有效吗？

网页端"记住"的东西都**存在浏览器本地**（`localStorage`）：

| 键名 | 内容 |
|:----------------------- |:--------------------------------------- |
| `zs-theme` | 主题（浅色 / 深色 / 跟随系统） |
| `zs-client-settings` | 视图模式、排序字段、排序方向、文件夹置顶、界面密度、字号、减少动画、背景噪点、桌面侧边栏是否默认折叠 |
| `zs-group-context` | 当前选择的小组上下文（`default` = 默认） |
| `zs-sidebar-collapsed` | **旧键**，桌面侧边栏是否折叠（`1` 折叠 / `0` 展开）。只在首次读取时迁移进 `zs-client-settings.sidebarCollapsed`，之后不再写入 |

换浏览器、换设备、清除浏览器数据后这些偏好会恢复默认；账号、文件、后台设置都在服务器上，不受影响。
