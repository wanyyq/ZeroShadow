## 文档约定

- 文中出现的路径都是**相对仓库根目录**的路径；打包成 exe 后，`.env` 与 `data/` 位于 `ZeroShadow.exe` 所在目录。
- "**后台**"指网页界面左侧导航的「设置」页面；只有超级管理员能看到管理类标签页。
- "**超管**"= 超级管理员，"**成员**"= 团队成员。
- 权限点名称使用后台界面上的中文名，括号内给出 `data/config.json` 里的字段名，例如「上传文件」(`memberPerms.upload`)。
- 所有"默认值"都指**首次运行、`data/config.json` 尚未存在**时的取值；此后以 `data/config.json` 中的实际值为准。
