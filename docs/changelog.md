## [2.1.0] - 2026-10-24

本次为纯新增功能：右键「转换为」把 Markdown 转成纯文本 / PDF、PNG 与 JPG 互转；服务端做成注册表驱动，
加一种格式只需注册一次。md→PDF 是完全自实现的（PDF 1.7 写出 + 字体子集化），**零新增依赖**。

> 一句话：**2.1.0 = 一个可扩展的「转换为」入口（4 个内置转换 + 3 个新接口）+ 自实现的 md→PDF + 新权限点 `convertFiles`**。

### 新增

- **文件转换（可扩展接口）**：文件右键菜单新增「转换为」子菜单，当前自带 4 个转换 ——
  `Markdown → 纯文本（.txt）`、`Markdown → PDF（.pdf）`、`PNG → JPG（.jpg）`、`JPG → PNG（.png）`。
  - 产物写在**源文件同目录**，重名自动 `名称 (1).ext`、**不覆盖已有文件**；转换是一个带进度的任务，
    完成后列表自动刷新。
  - 服务端 `server/src/convert/` 是**注册表驱动**：新增格式只需写一个转换器模块并在 `convert/index.js`
    里注册一次，**路由与前端都不用改**（右键菜单按 `GET /api/fs/convert/targets` 的返回动态渲染）。
  - 三个新接口：`GET /api/fs/convert/targets`、`POST /api/fs/convert`（返回 `jobId`）、
    `GET /api/fs/convert/status`。
- **md→PDF 自实现，零新增依赖**：自写 PDF 1.7 写出器 + TrueType 子集化，文字**可选中复制 / 搜索**、
  链接可点击、A4 分页带页脚页码；支持标题 / 列表 / 代码块 / 引用 / 表格 / 分割线 / 行内样式。
  - 字体自动发现：`CONVERT_PDF_FONT` → `data/fonts/` → **扫描平台字体目录**（Windows 的
    `%WINDIR%\Fonts` 与用户字体目录、macOS 的 `/System/Library/Fonts`、Linux 的 `/usr/share/fonts` 等）
    → 兜底绝对路径；候选按常见中文字体名排序后逐个真解析验证。**不再硬编码 `C:/Windows/Fonts`**。
    启动横幅新增一行 `PDF 字体: <路径>`，找不到时另记一条 `pdf_font_missing` 日志。
  - 字体一个都找不到时**拒绝转换**（`api.fs.convert_no_cjk_font`）并提示把字体放进 `data/fonts/`，
    而不是把中文写成 `?` 交出一份内容已损坏的 PDF。纯 ASCII 文档不受影响。
- **新权限点 `convertFiles`（后台名称「文件转换」，默认开启）**：受写操作总开关 `fileWrite` 约束、
  可被小组收窄；**访客恒不可转换**。权限点总数 **19 → 20**。
- **并发闸门（`server/src/convert/queue.js`）**：同时最多 4 个转换在跑、最多 32 个排队，
  排满直接回 503（`api.fs.convert_busy`）—— 大图转换是纯 CPU / 原生解码，不设闸门会让
  同组的文件列表卡住。
- **新测试脚本 `scripts/convert-test.mjs`**：44 条断言（Markdown 解析、md→txt、md→PDF 的结构 /
  字体子集 / 文本可复制性、图片互转、注册表校验、并发闸门），**不需要起服务**，产物写系统临时目录。

### 变更

- 版本号 `2.0.0` → `2.1.0`，同步 6 处：根 / `server` / `web` 三个 `package.json`、`/api/meta`、
  `web/src/version.ts`、`web/public/sw.js`。
- **多语言**：新增 `ui.browser.convert_to`、`ui.convert.*`（4 条目标文案）、
  `ui.operations.convert_done(_named/_failed)`、`ui.settings.perms.convert_files`、
  `ui.settings.groups.perm_convert_files` 与 9 条 `api.fs.convert_*` 错误文案，
  **7 套语言（zh / zh-TW / zh-HK / en / ja / es / fr）全部补齐**；新增一个文案分区文件
  `web/src/locales/<语言>/convert.json`。
- 后台「设置 → 权限 → 成员权限 → 高级功能」多一项「文件转换」；小组编辑的「高级权限」分组
  多一项同名开关。
- **WebDAV 后台卡片新增「资源管理器地址」**（Windows UNC 写法，按当前访问方式生成），并写明
  资源管理器要用「添加一个网络位置」而不是「映射网络驱动器」。
- 新增 `scripts/webdav-test.mjs`（70 项）：照资源管理器 / Finder 的真实请求序列跑一遍 WebDAV。

### 修复

- **WebDAV 挂不上 / 挂上后保存失败**（详见下面是同批修复）：
  - `getetag` 写反（目录有、文件没有），且 PROPFIND / GET / PUT 三处 ETag 算法互不相同 ——
    "从列表拿 ETag 再保存"永远判 412。现统一为 `davEtag()` 一个来源：`"s-<mtimeMs>-<size>"`；
  - `PROPPATCH` 回的是非法元素（`<D:multivaluedate/>`），客户端判定属性写入失败；
    现按 RFC 回 `207 multistatus` 并真的应用 `Win32LastModifiedTime`；
  - `OPTIONS /` 不声明 DAV，客户端探测 authority 根后直接放弃挂载；现在根上也声明；
  - `Destination` 连端口一起比，反代后面所有 COPY / MOVE 都 502；现在只比 hostname
    （并接受 `X-Forwarded-Host`），真的跨站仍然拒绝；
  - `PROPFIND` 无视请求体，`creationdate` / `lockdiscovery` 等属性永远拿不到；
    现在按 RFC 拆 200 / 404 两个 `propstat`；
  - `Depth: infinity` 的拒绝从 JSON 改成 RFC 形式（`403` + `<D:propfind-finite-depth/>`）；
  - `LOCK` 对不存在的文件也回 200，RFC 要求 201（否则新建文件会被当成覆盖，还要 delete 权限）；
  - `PROPFIND` / `PROPPATCH` / `LOCK` 的请求体没读干净，部分客户端会看到连接重置；
  - 所有 DAV 响应统一带 `DAV` / `Allow` / `Cache-Control: no-store`（Windows 缓存很激进）。

## [2.0.0] - 2026-10-25

首个正式版：把 beta1–beta5 的成果（WebDAV 转正、缩略图与虚拟滚动、弱网优化、插件体系、品牌改造）合并发布，并补上一整轮安全审计与修复，同时把文档重新与代码对齐。

> 一句话：**2.0.0 = beta1–beta5 的功能全量落地 + 一轮完整安全审计（20 项新发现、7 项已修）+ 文档与代码重新对齐**。

### 修复（安全）

- **「对访客隐藏」可被 Windows 8.3 短名绕过**（匿名可触发）：打包下载、在线压缩、WebDAV、分享链接四处都改用**规范化后的相对路径**做可见性判定，不再用请求里的原串比较。
- **WebDAV `PUT` 覆盖会绕过回收站**：覆盖已有文件现在需要「删除」权限，旧文件先进回收站（与 Web 端 `/upload`、`/rename` 一致），中途失败不会动原文件。
- **分享密码可换 IP 爆破**：密码校验接口补上接口限流，锁定新增「按分享 token 全局」维度，伪造 `X-Forwarded-For` 换 IP 也无法绕过。
- **插件总开关不生效**：主题 CSS、运行时插件清单、插件入口 HTML 三条**公开**接口现在也受总开关约束。
- **插件设置对匿名访客可见**：设置项默认不下发给浏览器，只有 manifest 里标了 `public: true` 的才会下发。
- **插件沙箱可被导航劫持**：`fileType` 的 iframe 消息增加来源校验，入口文档一旦被导航即断链，避免把一次导航升级成"任意文件读取接口"。
- **WebMCP 默认授权**：浏览器内 AI 代理改为**默认关闭**，需在「设置 → 外观」显式开启；关闭开关或登出立即撤销全部工具。

### 变更

- 版本号 `2.0.0-beta` → `2.0.0`：根 / `server` / `web` 三个 `package.json`、`/api/meta`、`web/src/version.ts`、`web/public/sw.js` 共 6 处同步。
- `README.md`、`SECURITY-AUDIT.md` 里"当前版本"的过期标注已修正。

### 文档

- 新增《[服主入门](服主入门.md)》：首次登录与改密码、六步安全基线、建成员与小组、19 项权限基线与上限、日常运维四件事、一页验收清单、十种常见误配（MDX 站同步一篇）。
- 修正两棵文档树的**中间件顺序**（原文把 body parser 画在鉴权之前，与代码相反）并补上 `createWebdavRouter()`。
- 插件设置的 `public` 规则、WebMCP 的授权与提示注入链路、分享密码的三维限速、备份受管文件清单（4 → 6）等写入文档与界面文案。

## [2.0.0-beta] - 2026-10-25

v2.0 的第一个 beta：**定位从「局域网网盘」改为「工作室网盘」**，WebDAV 转正，
补上缩略图、虚拟滚动与弱网优化，并落地插件体系（主题 + JSON Schema 设置）。

### 新增

- **WebDAV 正式化**：后台可开关与改挂载路径、**运行时生效不必重启**；`.env` 退为默认值，
  `data/config.json` 优先。补了一批限制（`Depth: infinity` 403、列目录 5000 项、锁表上限、
  请求体 64 KB、每分钟 1200 次、跨主机 `Destination` 502、Basic 校验缓存 60 秒）。
- **网格缩略图**：服务端 `sharp` 出 webp 小图，内容寻址缓存 + 并发闸门 + 30 天/512 MB 清理；
  `sharp` 不可用时（exe 发布包）自动退回图标。
- **虚拟滚动**：列表窗口化渲染（只挂视口附近的行），网格渐进渲染（滚到底追加一批）。
- **弱网 / 内网穿透优化**：幂等请求自动重试与退避、20 秒超时、离线提示（8 秒节流）、
  Service Worker 缓存构建产物与字体（仅 HTTPS / localhost）、下载 `Range` 与 `If-None-Match`。
- **插件体系**：`manifest.json` + `apiVersion` + 类型/权限白名单、安装时逐条解 zip 校验、
  **总开关默认关、装完默认禁用**、设置项由 **JSON Schema** 自动渲染表单。三种类型都已可用：
  - **主题**：声明式 CSS 令牌（名与值都校验），服务端拼好带作用域的 CSS，同一时间只有一个生效；
  - **文件类型（预览）**：预览页的沙箱 iframe（`sandbox="allow-scripts"` + `connect-src 'none'`），
    读写通过 `postMessage` 请求宿主代执行，保存带版本比对、冲突即 409；
  - **服务端**：独立子进程 + `actions` 白名单 + 5 秒超时杀进程 + 环境变量白名单。
    **不是 OS 级沙箱**，只装可信插件。
- 新增 [插件开发](插件开发.md) 文档（含两种运行时的协议与最小可运行示例）。

### 变更

- **品牌定位**：README、文档、mdx 首页、关于页标语（8 种语言）、网页标题与描述统一改为
  「轻量级工作室网盘 · 一款极简好用的团队私有网盘」，不再以"局域网"作为卖点。
- 版本号统一 `2.0.0-beta`（三个 `package.json`、`/api/meta`、`web/src/version.ts`）。
- `使用手册` 的侧边栏示意图不再写死版本号。

### 修复

- 冒烟测试里 `Range` 头与同名变量的问题（改用 `AddRange()`、局部变量改名）。
- 根 `package.json` 被写入 BOM 导致 Vite 构建失败（PostCSS 解析报错），已剥离。

### 移除

- `resources/tailwindcss.min.js`（269.8 KB，全站零引用）。
- WebDAV 的"实验性"定位与静态 404 兜底。

### 升级说明

- 以前用 `WEBDAV=1` 的实例继续生效；后台改过之后以 `data/config.json` 为准。
- 插件默认关闭，升级不会自动启用任何东西。
- `ZeroShadow.exe` 发布包没有缩略图（原生模块无法内联），网格退回图标。
- Service Worker 只在 HTTPS / localhost 生效，升级后需一次导航才会更新。

## [1.2.3] - 2026-10-18

本次以**第二轮安全审计修复**为主，同时包含上一轮「安全审计回归 + Office 预览正确性 + 右键菜单」的未发布改动。

### 安全（第二轮审计）

- **路径判定一律先规范化**：`resolveAny()` 现在用 `realpathSync.native` 把 Windows 8.3 短名与符号链接解析成真实路径后，
  再做边界 / 可见性 / 敏感名判定 —— 修掉 `path=CONFID~1/…` 能读「对访客隐藏」目录、`path=ENV~1` 能读 `.env` 的问题；
  NTFS 备用数据流（`name::$DATA`）在 Windows 上直接拒绝。
- **覆盖即删除，必须过 `delete` 权限并进回收站**：`rename` / `move` / `copy` / 合并 / 覆盖上传，
  以及 WebDAV `COPY` / `MOVE` 的覆盖分支，以前只校验各自权限点且直接 `fs.rm`；
  现在需要 `delete` 权限并走回收站。WebDAV 另补「源必须先存在」「目标不能是源的上级目录」。
- **超管账号不再能被匿名锁死**：登录改为「超管先验口令、口令错才判锁定」—— 错误口令仍会被 IP + 账号双维度锁定，
  但正确口令永远能进（旧实现任何人打 10 次错密码就能把唯一的管理员挡在门外 5~30 分钟，且可无限续期）。
- **登出即吊销**：成员 `tokenVersion + 1`、超管会话代次 `+ 1`，已发出的 JWT 立刻失效
  （此前只清 Cookie，被窃令牌在 72 小时内仍然可用）。
- **OOXML 元数据解压加上限**：`docProps` 的 deflate 解压限制输出 1 MB，
  堵住「4 MB 压缩包解出 GB 级内存」的单请求 DoS。
- **WebDAV 两个数据面问题**：PUT 不再被全局 `express.json()` 提前读空
  （此前 `Content-Type: application/json` 的 PUT 会静默写成 0 字节）；GET / HEAD 的 ETag 对大文件改用 `mtime-size`，
  不再把整文件读进内存。
- **请求体解析移到鉴权之后**：未认证者不能再强迫服务解析 16 MB 请求体；`/save-file`、`/file` 补了速率限制。
- **分享不能越权暴露子树**：创建时记录创建者的可见范围快照，访问 `list` / `download` 时逐条复判；
  公开分享接口补限流、目录统计加 10 秒缓存、下载计数只在成功且非 Range 时累加。
- **分享归属改按账号**：记录 `ownerId`（老数据自动回填），改名不再让分享变「无主」，同名新账号也不能继承旧链接；
  禁用成员一并吊销其分享。
- **凭据类文件名一律拦截**：`.env`、`*.env`、`.env.*`、`.jwt-secret*` 在网盘内（含软目录映射）一律 404，
  覆盖 `.migration-backup/server.env` 这类历史副本；`data/lang` 也加入敏感条目表。
- **`htmlPreview` 服务端生效**：无该权限时 HTML / SVG 按附件下发（仍保留 `CSP: sandbox` 第二道防线），
  不再只靠前端拦。
- **`/api/fs/file` 需要 `preview` 或 `downloadFile`**：只给 `browse` 的角色不能再读文件全文。
- **只读角色真正只读**：`compressZip` / `extractZip` / `downloadUrl` 与 `fileWrite` 取与；`uploadFolders` 开始真正校验。
- **访客写权限加总开关** `guestWrite`（默认关）：`editFiles` / `compressZip` / `extractZip` 只有在它打开时才生效。
- **其他**：备份快照副本补 `chmod 600`；原子写的临时文件不再能被 `dotfiles:"allow"` 下载；
  限流补「按 TCP 对端」兜底桶（伪造 `X-Forwarded-For` 不再能无限换桶）；
  超管 JWT 里的口令指纹改为以 `JWT_SECRET` 为密钥的 HMAC。

### 变更（v1.2.3 行为变化）

- **小组「默认上下文」语义收紧**：成员未指定小组（或指定了不属于自己的小组）时，
  有效权限取**所属各组权限的交集**（deny 优先），可见范围取**所属各组范围的并集** ——

  外部映射目录会标出「只读」。
- 文件预览页的文本类文件在 `.md` 上新增「源码 / 预览」切换按钮。
- **前端所有用户可见文案改为命名键**（约 1200 条），译文放在
  `web/src/locales/<语言>/<区域>.json`，构建期合并；模块级文案表改为**存键**、渲染时翻译。

## [1.1.2] - 2026-10-06

以「防止数据丢失」为核心的一次更新，并提供两个新能力（其中一个带实验标记）。

### 新增

- **回收站**：删除不再直接销毁文件，而是移入 `data/trash/`，可在「设置 → 回收站」
  里还原、覆盖还原、彻底删除或一键清空；保留天数可配置（默认 30 天），
  超期由服务启动时与每 6 小时的维护任务自动清理。
  - 删除时若回收站不可用（`data/` 只读、磁盘满等），会降级为直接删除并**明确告知**
    哪些项目没有进回收站；
  - 回收站数据刻意放在 `data/` 而**不在网盘根目录内**，否则会被列目录、搜索、打包；
  - WebDAV 的 `DELETE` 与 Web 端行为一致（同样进回收站）。
- **并发编辑保护**：在线编辑器打开时拿到内容版本串（`mtime-size-内容哈希`），
  保存时若服务端内容已变则**拒绝写入并返回 409**，界面给出「重新加载」与
  「强制覆盖」两个选项，而不是静默覆盖别人刚保存的内容。
- **审计日志导出**：`GET /api/admin/logs/export?format=jsonl|csv`，可按天数、级别、
  关键词、「仅审计事件」筛选后导出全部匹配记录。CSV 带 UTF-8 BOM 与 CRLF 换行，
  Excel 打开不乱码。
- **WebDAV 挂载（实验性 / Beta，默认关闭）**：设 `WEBDAV=1` 后开启，挂载点 `/dav`
  （可用 `WEBDAV_PATH` 改）。支持 `OPTIONS / PROPFIND / GET / HEAD / PUT / MKCOL /
  DELETE / COPY / MOVE / LOCK / UNLOCK`，可挂载为网络盘。

### 变更

- `/api/fs/delete` 返回 `{ deleted, trashed, permanentlyDeleted }`。
- `GET /api/fs/file` 增加 `baseVersion`，`POST /api/fs/save-file` 接受 `baseVersion`。
- 错误响应在 `err.code` 存在时透传 `code` 与 `currentVersion`。

### 修复

- **`/dav` 未启用时返回前端首页**：`GET /dav`、`/dav/` 会被 SPA fallback 接住返回
  网盘界面。现在统一 404 并提示"请在 .env 设置 WEBDAV=1"。
- **`data/` 不可写会让整个服务无法启动**：现在降级处理并在启动日志说明原因。

### 实验性功能：WebDAV 的风险须知

| 风险 | 说明 |
|:--|:--|
| **凭据反复明文传输** | 客户端普遍只支持 HTTP Basic，用户名密码会在每个请求里重复发送；请只在 HTTPS 或可信内网使用 |
| **仅成员账号可用** | 不接受超管账号，也不接受浏览器 Cookie 会话（否则会成为绕过 CSRF 的后门） |
| **客户端实现差异** | 各家客户端协议细节差异大，无法像 HTTP 接口那样被完整覆盖 |
| **锁是"礼节性"的** | `LOCK` 只让客户端认为锁生效；真正的并发保护靠版本比对 |

## [1.1.1] - 2026-10-06

本次以**修复缺陷**为主，并新增一个面向旧浏览器的兼容模式页面。

### 新增

- **兼容模式页面 `/robustness/index.html`**：面向跑不动 React / Tailwind 的老机器
  （IE11、Win7 上的老版 Chrome）。原生 HTML + CSS + **ES5** 手写，不引入任何外部库、
  不参与前端构建、**不放宽任何服务端安全设置**。提供登录、浏览目录、下载 / 打包下载、
  上传文件、上传文件夹、新建文件夹、重命名、删除、复制 / 剪切 / 粘贴 / 复制到…，
  以及图片 / 视频 / 音频 / PDF / 文本的预览（走浏览器原生能力，不支持时明确提示）。
  - 入口：文件浏览器底部状态条右侧，以及**登录页**底部（未登录时也能进）；
  - 直接访问 `/robustness/` 也会正确打开；
  - 深浅色偏好独立存储（`zs-robustness-theme`），与正常页面的 `zs-theme` 互不影响。
  - 用法与限制见[使用手册 · 兼容模式](使用手册.md#兼容模式旧浏览器专用)，
    实现约束见[开发者指南 · 兼容模式](开发者指南.md#45-兼容模式robustness)。

- `/api/auth/me` 新增 `caseInsensitive` 字段，告知前端**服务端所在文件系统是否区分大小写**。

### 修复

**数据与状态**

- **顶栏所选小组刷新后丢失**：`GroupsProvider` 的回退逻辑没有等身份就绪，而身份初始值是
  `guest`，于是首帧就把 localStorage 里记住的小组覆写成了「默认」。现在等 `ready` 之后再判断。
- **长任务面板出现"看不见却还在弹提示"**：压缩 / 解压 / 链接下载的任务在加入列表时会把
  仍在运行的任务挤出面板，但它对应的轮询定时器没被回收，会继续更新已不在界面上的任务状态
  并弹 toast。现在改为幂等对账：只有"仍在列表里的运行中任务"才持有轮询。
- **头像本地缓存越攒越多**：清理逻辑只遍历"渲染过"的头像，从未显示过的条目会一直留在
  IndexedDB 里。现在按缓存库的全部键与服务端列表比对后清理。
- **批量重置密码静默失败**：逐条重置时没有错误处理，任一条失败即为未处理的 Promise
  rejection，而成功提示照常弹出。现在逐条捕获并汇总失败名单。

**界面与交互**

- 预览页「放大」按钮首次点击的倍率被覆盖（连续两次 `setScale`），实际只放大到 1.5 倍。
- 成员表为空时的占位行 `colSpan` 与表头列数不一致（7 vs 6）。
- 「恢复默认外观」承诺重置主题但实际不会（主题存在 `ThemeProvider` 自己的 `zs-theme` 键里）。
- 同一冲突判定在重命名对话框里用了大小写**敏感**的比较，与服务端规则不一致：Windows 上
  仅改大小写的重命名会被误判为文件冲突并给出对文件无意义的「覆盖 / 合并」。
- 搜索结果里双击文件时，`下载权限 || 预览权限` 的写法导致**只有预览权限的人依然会下载**。
- 搜索模式下拖入文件会静默上传到当前目录（遮罩不显示，但放置没有被拦住）。
- 复制到剪贴板的失败路径没有提示：`navigator.clipboard` 不存在时可选链会让两个回调都不执行，
  表现是"点了复制没有任何反应"。共修正 4 处。
- 二次确认框里的操作失败后对话框已经关闭，用户只能靠一条 toast 猜测结果；现在支持把动作交给
  确认框执行 —— 成功才关闭，失败会留在框内显示原因。
- HTML 预览页「在新标签页打开」缺少 `noopener`。

**配置与文案**

- 「数据与保留」页缺少 `backupEnabled`（启用数据快照）开关，此前只能手改 `data/config.json`。
- 日志与指标页硬编码「磁盘保留 7 天」，与可配置的 `metricsRetentionDays` 可能矛盾。

**兼容模式页面自身**

- 「上传文件夹」按钮的特性检测写法无效（`setAttribute` 设上的自定义属性不会变成同名 JS 属性），
  在 IE11 上会显示按钮却点不动；改用 `"webkitdirectory" in input` 检测。
- 拖入文件夹时旧浏览器会给出一个 0 字节、无 MIME 的条目，原样上传会让服务端存下同名空文件；
  现在忽略并提示改用「上传文件夹」按钮。

**服务端路由**

- 访问目录形式 `/robustness/` 拿不到 `index.html`（`express.static` 配了 `index: false`），
  会静默落到 SPA fallback 返回首页 —— 表现是"打开兼容模式却跳回主页面"。
  现在把 `/robustness` 与 `/robustness/` 显式重定向到 `/robustness/index.html`；
  文件尚未生成时（改了 `public/` 但没 `pnpm build`）返回 **503** 并提示先构建，而不是返回首页。

### 移除

- 死代码清理：`avatar-cache.ts` 的 `invalidateAvatars()` / `releaseAll()`（全库无调用）、
  `app-shell.tsx` 中从未被消费且从未渲染的 `searchEl`。
  同时把 `fetchAdminGroups()` 的 `leaderCaps` 从 `string[]` 收紧为真实联合类型。

### 测试与文档

- `smoke-test.ps1` 新增第 10 组断言（兼容模式页面可访问、无内联脚本、三个静态资源可达、首页含入口）。
- 使用手册新增「兼容模式（旧浏览器专用）」一节；开发者指南新增「4.5 兼容模式」一节。
