## [1.2.0] - 2026-10-11

### 新增

- **Markdown 预览渲染**：`.md`（以及 `.markdown` / `.mdown` / `.mkd` / `.mkdn`）在预览页
  默认**按 Markdown 排版显示**，右上角可一键切回源码。支持标题（含锚点 id）、围栏代码块、
  有序 / 无序 / 嵌套列表、任务列表、表格（含对齐）、引用、水平线、粗体 / 斜体 / 删除线、
  链接、图片、自动链接与硬换行。
  - 渲染器是自带的极简实现（`web/src/lib/markdown.ts`），**不引入任何第三方 Markdown 库**，
    前端产物只增加约 8KB（构建后 minify 体积，含样式约 13KB），远低于 15KB 的预算；
  - 采用**先整体转义、再解析**：文件里的原始 HTML 一律按纯文本显示（页面顶部给出提示），
    `javascript:` / `vbscript:` / `data:` 链接降级为纯文本，因此那处
    `dangerouslySetInnerHTML` 没有 XSS 通道；
  - **兼容模式（`/robustness/index.html`）保持不变**：它对 `.md` 仍是等宽字体只读展示。
- **文件详细信息（文件属性）**：「详细信息」对话框新增按**文件内容**解析的元数据，
  新增接口 `GET /api/fs/details`（权限沿用「查看详情」`details`，同样受限流保护）：
  - **签名识别**：按文件头魔数识别真实格式与 MIME 类型，并给出前 16 字节的十六进制签名，
    扩展名被改过也骗不过（`.zip` 改名成 `.png` 会被点出来）；覆盖 PNG / JPEG / GIF / BMP /
    TIFF / WebP / ICO / PSD / PDF / ZIP 家族（含 docx / xlsx / pptx / apk / jar / epub）、
    RAR / 7z / GZip / BZip2 / XZ / Zstd / TAR、MP4 / MOV / MKV / WebM / AVI / FLV / MPEG-TS、
    MP3 / FLAC / Ogg / WAV / MIDI、ELF / PE / Mach-O / class / wasm、SQLite、字体与 OLE2 等；
  - **校验和**：MD5 / SHA-1 / SHA-256 与内容版本串（与 `baseVersion`、WebDAV `ETag` 同源），
    超过 64MB 的文件会跳过并说明原因；
  - **图像与 EXIF**：像素尺寸 / 像素量 / 宽高比 / 位深 / 色彩模式；EXIF 含相机厂商与型号、
    拍摄时间、ISO、曝光时间、光圈、焦距、闪光灯、镜头、作者与版权、GPS 经纬度与方向；
  - **文档属性**：PDF 的标题 / 作者 / 创建程序 / 生成工具 / 时间；docx / xlsx / pptx 的
    标题、创建者、最后修改者、创建与修改时间、修订次数、公司、页数与字数；PNG 文本块；
  - **媒体信息**：MP4 / MOV / M4A 时长（`moov` 在文件末尾也能读）、WAV 声道与时长、
    FLAC 采样率、MP3 的 ID3 标签；
  - **文本信息**：编码（含是否为推测、是否带 BOM）、换行风格、行数、字符数；
  - 全程**不把文件整个读进内存**（解析只读头尾各 64KB、哈希流式且限 64MB、文本统计限 8MB），
    且任意一段解析失败都只让那段为空，不影响其它信息。
- **多语言（i18n）**：界面自带**简体中文**与 **English**，可在「设置 → 外观 → 界面语言」
  或登录页右上角一键切换 —— 立即生效、只影响本机浏览器（`localStorage` 的 `zs-lang`）。
  - **可由服务端扩展**：把 `<语言代码>.json` 放进 `data/lang/` 就是一个新语言，
    **不需要改代码、不需要重启**；首次启动会自动创建该目录并写入 `README.md`；
  - 语言文件支持 `_meta.name`（选择器里的显示名）与 `_meta.base`（没翻译到的键回落到
    `zh` / `en`），所以**先翻一半就能用**；「设置 → 外观」还能**导出翻译模板**（含全部键）；
  - 站点默认语言由 `data/config.json` 新增的 `defaultLang` 决定；用户没选过时按
    「站点默认 → 浏览器语言 → 中文」；
  - 覆盖三层：**前端界面 + 服务端返回给用户的提示 + 兼容模式页**；服务端错误新增可选的
    `errorKey` / `errorParams`（`error` 仍是中文原文，脚本与 curl 行为不变），
    「详细信息」的字段改为 `{ key, label, value, unitKey }`（中文界面逐字不变）；
  - 新接口 `GET /api/i18n` 与 `GET /api/i18n/:code`（**免登录**，登录页也要显示选择器）；
  - **日志与审计记录的内容仍是中文**，但日志查看界面会跟着换语言。
- **文案校验脚本** `i18n-check.mjs`：键完整性（缺 `zh` 是错误、缺 `en` 是警告）、死键、
  重复定义、`data/lang` 文件合规性，以及剩余硬编码中文统计（`--strict` / `--list-cn`）。

### 变更

- 「详细信息」对话框改版：按「基本信息 / 内容识别 / 校验和 / 图像 / 文档属性 / 媒体信息 /
  文本信息」分区显示，每行可单独复制，底部可「复制全部信息」；同时补上访问时间与状态变更时间，
  外部映射目录会标出「只读」。
- 文件预览页的文本类文件在 `.md` 上新增「源码 / 预览」切换按钮。
- **前端所有用户可见文案改为命名键**（约 1200 条），译文放在
  `web/src/locales/<语言>/<区域>.json`，构建期合并；模块级文案表改为**存键**、渲染时翻译。
- `server/src/http.js` 新增共用的 `httpError(status, message, extra)`，合并 5 处重复定义。
- 写死的 `toLocaleString("zh-CN")` 改为跟随当前界面语言。

### 修复

- 上传取消的判定由「错误文案包含"取消"」改为 `aborted` 标志（多语言化后按字符串判断必然失效）。

## [1.1.2] - 2026-10-06

以「防止数据丢失」为核心的一次更新，并提供两个新能力（其中一个带实验标记）。

### 新增

- **回收站**：删除不再直接销毁文件，而是移入 `data/trash/`，可在「设置 → 回收站」
  里还原、覆盖还原、彻底删除或一键清空；保留天数可配置（默认 30 天），
  超期由服务启动时与每 6 小时的维护任务自动清理。
  - 删除时若回收站不可用（`data/` 只读、磁盘满等），会降级为直接删除并**明确告知**
    哪些项目没有进回收站；
  - 回收站数据刻意放在 `data/` 而**不在网盘根目录内**，否则会被列目录、搜索、打包；
  - WebDAV 的 `DELETE` 与 Web 端行为一致（同样进回收站）。
- **并发编辑保护**：在线编辑器打开时拿到内容版本串（`mtime-size-内容哈希`），
  保存时若服务端内容已变则**拒绝写入并返回 409**，界面给出「重新加载」与
  「强制覆盖」两个选项，而不是静默覆盖别人刚保存的内容。
- **审计日志导出**：`GET /api/admin/logs/export?format=jsonl|csv`，可按天数、级别、
  关键词、「仅审计事件」筛选后导出全部匹配记录。CSV 带 UTF-8 BOM 与 CRLF 换行，
  Excel 打开不乱码。
- **WebDAV 挂载（实验性 / Beta，默认关闭）**：设 `WEBDAV=1` 后开启，挂载点 `/dav`
  （可用 `WEBDAV_PATH` 改）。支持 `OPTIONS / PROPFIND / GET / HEAD / PUT / MKCOL /
  DELETE / COPY / MOVE / LOCK / UNLOCK`，可挂载为网络盘。

### 变更

- `/api/fs/delete` 返回 `{ deleted, trashed, permanentlyDeleted }`。
- `GET /api/fs/file` 增加 `baseVersion`，`POST /api/fs/save-file` 接受 `baseVersion`。
- 错误响应在 `err.code` 存在时透传 `code` 与 `currentVersion`。

### 修复

- **`/dav` 未启用时返回前端首页**：`GET /dav`、`/dav/` 会被 SPA fallback 接住返回
  网盘界面。现在统一 404 并提示"请在 .env 设置 WEBDAV=1"。
- **`data/` 不可写会让整个服务无法启动**：现在降级处理并在启动日志说明原因。

### 实验性功能：WebDAV 的风险须知

| 风险 | 说明 |
|:--|:--|
| **凭据反复明文传输** | 客户端普遍只支持 HTTP Basic，用户名密码会在每个请求里重复发送；请只在 HTTPS 或可信内网使用 |
| **仅成员账号可用** | 不接受超管账号，也不接受浏览器 Cookie 会话（否则会成为绕过 CSRF 的后门） |
| **客户端实现差异** | 各家客户端协议细节差异大，无法像 HTTP 接口那样被完整覆盖 |
| **锁是"礼节性"的** | `LOCK` 只让客户端认为锁生效；真正的并发保护靠版本比对 |

## [1.1.1] - 2026-10-06

本次以**修复缺陷**为主，并新增一个面向旧浏览器的兼容模式页面。

### 新增

- **兼容模式页面 `/robustness/index.html`**：面向跑不动 React / Tailwind 的老机器
  （IE11、Win7 上的老版 Chrome）。原生 HTML + CSS + **ES5** 手写，不引入任何外部库、
  不参与前端构建、**不放宽任何服务端安全设置**。提供登录、浏览目录、下载 / 打包下载、
  上传文件、上传文件夹、新建文件夹、重命名、删除、复制 / 剪切 / 粘贴 / 复制到…，
  以及图片 / 视频 / 音频 / PDF / 文本的预览（走浏览器原生能力，不支持时明确提示）。
  - 入口：文件浏览器底部状态条右侧，以及**登录页**底部（未登录时也能进）；
  - 直接访问 `/robustness/` 也会正确打开；
  - 深浅色偏好独立存储（`zs-robustness-theme`），与正常页面的 `zs-theme` 互不影响。
  - 用法与限制见[使用手册 · 兼容模式](使用手册.md#兼容模式旧浏览器专用)，
    实现约束见[开发者指南 · 兼容模式](开发者指南.md#45-兼容模式robustness)。

- `/api/auth/me` 新增 `caseInsensitive` 字段，告知前端**服务端所在文件系统是否区分大小写**。

### 修复

**数据与状态**

- **顶栏所选小组刷新后丢失**：`GroupsProvider` 的回退逻辑没有等身份就绪，而身份初始值是
  `guest`，于是首帧就把 localStorage 里记住的小组覆写成了「默认」。现在等 `ready` 之后再判断。
- **长任务面板出现"看不见却还在弹提示"**：压缩 / 解压 / 链接下载的任务在加入列表时会把
  仍在运行的任务挤出面板，但它对应的轮询定时器没被回收，会继续更新已不在界面上的任务状态
  并弹 toast。现在改为幂等对账：只有"仍在列表里的运行中任务"才持有轮询。
- **头像本地缓存越攒越多**：清理逻辑只遍历"渲染过"的头像，从未显示过的条目会一直留在
  IndexedDB 里。现在按缓存库的全部键与服务端列表比对后清理。
- **批量重置密码静默失败**：逐条重置时没有错误处理，任一条失败即为未处理的 Promise
  rejection，而成功提示照常弹出。现在逐条捕获并汇总失败名单。

**界面与交互**

- 预览页「放大」按钮首次点击的倍率被覆盖（连续两次 `setScale`），实际只放大到 1.5 倍。
- 成员表为空时的占位行 `colSpan` 与表头列数不一致（7 vs 6）。
- 「恢复默认外观」承诺重置主题但实际不会（主题存在 `ThemeProvider` 自己的 `zs-theme` 键里）。
- 同一冲突判定在重命名对话框里用了大小写**敏感**的比较，与服务端规则不一致：Windows 上
  仅改大小写的重命名会被误判为文件冲突并给出对文件无意义的「覆盖 / 合并」。
- 搜索结果里双击文件时，`下载权限 || 预览权限` 的写法导致**只有预览权限的人依然会下载**。
- 搜索模式下拖入文件会静默上传到当前目录（遮罩不显示，但放置没有被拦住）。
- 复制到剪贴板的失败路径没有提示：`navigator.clipboard` 不存在时可选链会让两个回调都不执行，
  表现是"点了复制没有任何反应"。共修正 4 处。
- 二次确认框里的操作失败后对话框已经关闭，用户只能靠一条 toast 猜测结果；现在支持把动作交给
  确认框执行 —— 成功才关闭，失败会留在框内显示原因。
- HTML 预览页「在新标签页打开」缺少 `noopener`。

**配置与文案**

- 「数据与保留」页缺少 `backupEnabled`（启用数据快照）开关，此前只能手改 `data/config.json`。
- 日志与指标页硬编码「磁盘保留 7 天」，与可配置的 `metricsRetentionDays` 可能矛盾。

**兼容模式页面自身**

- 「上传文件夹」按钮的特性检测写法无效（`setAttribute` 设上的自定义属性不会变成同名 JS 属性），
  在 IE11 上会显示按钮却点不动；改用 `"webkitdirectory" in input` 检测。
- 拖入文件夹时旧浏览器会给出一个 0 字节、无 MIME 的条目，原样上传会让服务端存下同名空文件；
  现在忽略并提示改用「上传文件夹」按钮。

**服务端路由**

- 访问目录形式 `/robustness/` 拿不到 `index.html`（`express.static` 配了 `index: false`），
  会静默落到 SPA fallback 返回首页 —— 表现是"打开兼容模式却跳回主页面"。
  现在把 `/robustness` 与 `/robustness/` 显式重定向到 `/robustness/index.html`；
  文件尚未生成时（改了 `public/` 但没 `pnpm build`）返回 **503** 并提示先构建，而不是返回首页。

### 移除

- 死代码清理：`avatar-cache.ts` 的 `invalidateAvatars()` / `releaseAll()`（全库无调用）、
  `app-shell.tsx` 中从未被消费且从未渲染的 `searchEl`。
  同时把 `fetchAdminGroups()` 的 `leaderCaps` 从 `string[]` 收紧为真实联合类型。

### 测试与文档

- `smoke-test.ps1` 新增第 10 组断言（兼容模式页面可访问、无内联脚本、三个静态资源可达、首页含入口）。
- 使用手册新增「兼容模式（旧浏览器专用）」一节；开发者指南新增「4.5 兼容模式」一节。

## [1.1.0] - 2026-10-01

一次较大的功能版本，引入协作与运维能力。

### 新增

- **小组**：成员可属于多个小组，顶栏切换上下文；小组只在全局权限基础上**收窄**，
  并支持可见范围白名单 / 黑名单（黑名单优先）；四项**组长能力**可由超管按组下放。
- **团队待办**：支持全员 / 小组 / 成员三种下发范围、优先级与截止日期、允许被指派者编辑。
- **用户头像**：浏览器端裁切为 128×128 WebP，服务端校验尺寸与体积；按 md5 增量同步并
  用 IndexedDB 缓存；未上传头像时生成统一样式的默认头像。
- **在线编辑器的编码支持**：由服务端识别编码（BOM / 无 BOM UTF-16 / 严格 UTF-8 / 逐候选打分），
  保留原始换行风格，保存时拒绝目标编码表示不了的字符而不是静默写成 `?`。
- **数据快照与回滚**：四个受管数据文件在覆盖写前自动快照 + 每日全量快照，可在后台一键回滚。
- 启动自检（损坏 JSON 隔离到 `data/backups/corrupt/`）、请求指标与慢请求、日志聚合统计。

### 变更

- 设置页按标签页拆分（外观 / 状态 / 日志与指标 / 成员 / 小组 / 权限 / 数据与保留 / 安全 / 公网）。

## [1.0.0] - 2026-09-27

首个公开发布版本。

### 新增

- 局域网网盘：文件浏览、上传（含文件夹）、流式下载、ZIP 打包下载、在线压缩与解压、

  链接下载 SSRF 防护、上传 HTML/SVG 的 CSP 沙箱、重型接口限流。
- 随包分发的兼容性测试脚本：`smoke-test.ps1`、`security-test.ps1`、`encoding-test.mjs`。
